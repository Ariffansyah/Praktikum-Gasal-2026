prompt: |
  Tugas

  Lengkapi sistem sivitas akademika yang memiliki peran ganda. `AsistenDosen` adalah mahasiswa sekaligus pengajar, sehingga dibentuk melalui multiple inheritance.

  1. Tujuan tugas

  Terapkan inheritance, `super()`, method overriding, multiple inheritance, factory method, dan static method.

  2. Spesifikasi class `User` (parent)

  - `total_user = 0` adalah class attribute. Setiap object baru menambahnya satu kali melalui nama class.
  - Constructor menerima `(nama, email)`.
  - `peran()` mengembalikan `"User"` dan `sapa()` mengembalikan `"Halo, <nama>"`.

  3. Spesifikasi class `Mahasiswa` (child dari `User`)

  - `batas_sks = 24` adalah class attribute.
  - Constructor menerima `(nama, email, nim)`. Gunakan `super().__init__(...)`, lalu simpan `nim` dan set `sks` awal `0`.
  - `@classmethod dari_teks(cls, teks)` menerima format `nama,email,nim` dengan pemisah koma. Ubah underscore pada nama menjadi spasi, lalu buat object melalui `cls(...)`.
  - `@staticmethod nim_valid(nim)` mengembalikan `True` jika panjang `nim` tepat 11 karakter dan seluruhnya digit.
  - `peran()` dioverride menjadi `"Mahasiswa"`.
  - `sapa()` dioverride. Jalankan `super().sapa()` lalu kembalikan `"<hasil super>, NIM <nim>"`.
  - `ambil_sks(jumlah)` menerima jika jumlah lebih dari nol dan `sks + jumlah` tidak melebihi `batas_sks`.

  4. Spesifikasi class `Pengajar` (parent kedua, berdiri sendiri)

  - Constructor menerima `(matkul)`, menyimpannya, dan set `jam_mengajar` awal `0`.
  - `peran()` mengembalikan `"Pengajar"`.
  - `mengajar(jam)` menerima jika jam lebih dari nol, lalu menambah `jam_mengajar`.

  5. Spesifikasi class `AsistenDosen(Mahasiswa, Pengajar)`

  - Constructor menerima `(nama, email, nim, matkul)`. Karena kedua parent memiliki constructor sendiri dengan parameter berbeda, panggil keduanya secara langsung melalui nama class, yaitu `Mahasiswa.__init__(self, ...)` dan `Pengajar.__init__(self, ...)`.
  - `peran()` dioverride menjadi `"Asisten Dosen"`. Tanpa override, `peran()` akan diambil dari `Mahasiswa` karena `Mahasiswa` ditulis lebih kiri pada daftar parent.
  - `sapa()` dioverride. Jalankan `super().sapa()` lalu kembalikan `"<hasil super>, asisten <matkul>"`. Urutan MRO class ini adalah `AsistenDosen`, `Mahasiswa`, `User`, `Pengajar`, sehingga `super().sapa()` menuju `Mahasiswa`.

  6. Program utama dan output

  Input: `data matkul sks jam asisten`, dengan `data` berformat `nama,email,nim`. Jika `asisten` bernilai `1`, object dibuat sebagai `AsistenDosen` dan `mengajar` dijalankan. Selain itu object dibuat melalui `Mahasiswa.dari_teks(data)` dan `Mengajar` bernilai `False`.

  Output harus tepat sepuluh baris: `Nama`, `Email`, `NIM`, `Peran`, `Sapa`, `NIM Valid`, `Ambil SKS`, `Total SKS`, `Mengajar`, dan `Total User`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - `dari_teks` memakai `cls(...)` sehingga tetap benar bila dipanggil dari class turunan.
  - `nim_valid` tidak menyentuh `self` maupun `cls`.
  - `sapa()` pada `AsistenDosen` memuat sapaan `User` dan `Mahasiswa` sekaligus.
  - `Total User` tetap `1` karena hanya satu object yang dibuat.
