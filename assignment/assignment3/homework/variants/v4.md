prompt: |
  Tugas

  Lengkapi hierarki akun bank kampus tiga tingkat. Biaya admin dan batas penarikan disusun bertingkat melalui `super()`.

  1. Tujuan tugas

  Terapkan inheritance, `super()`, method overriding bertingkat, multilevel inheritance, factory method, dan static method.

  2. Spesifikasi class `Akun` (parent)

  - `total_akun = 0` adalah class attribute. Setiap object baru menambahnya satu kali melalui nama class.
  - Constructor menerima `(pemilik, nomor, saldo)`. Simpan `saldo` sebagai integer karena nilainya datang sebagai teks.
  - `@classmethod dari_teks(cls, teks)` menerima bagian yang dipisah koma, mengubah underscore menjadi spasi, lalu membuat object melalui `cls(*bagian)`.
  - `@staticmethod nomor_valid(nomor)` mengembalikan `True` jika panjang nomor tepat 10 karakter dan seluruhnya digit.
  - `jenis()` mengembalikan `"Akun"`, `biaya_admin()` mengembalikan `5000`, `batas_tarik()` mengembalikan `500000`.
  - `tarik(jumlah)` menerima jika jumlah lebih dari nol, tidak melebihi hasil `self.batas_tarik()`, dan tidak melebihi `saldo`. Perhatikan bahwa `tarik` memanggil `self.batas_tarik()`, sehingga batas yang dipakai mengikuti class object yang sebenarnya.

  3. Spesifikasi class `AkunTabungan` (child dari `Akun`)

  - `jenis()` dioverride menjadi `"Akun Tabungan"`.
  - `biaya_admin()` dioverride. Ambil `super().biaya_admin()` lalu tambahkan `2000`.
  - `batas_tarik()` dioverride. Ambil `super().batas_tarik()` lalu tambahkan `500000`.

  4. Spesifikasi class `AkunPremium` (child dari `AkunTabungan`)

  - `jenis()` dioverride menjadi `"Akun Premium"`.
  - `biaya_admin()` dioverride. Ambil `super().biaya_admin()` lalu kurangi `7000`, sehingga hasil akhirnya nol.
  - `batas_tarik()` dioverride. Ambil `super().batas_tarik()` lalu tambahkan `4000000`.

  5. Program utama dan output

  Input: `data jumlah tipe`, dengan `data` berformat `pemilik,nomor,saldo`. Nilai `tipe` `2` membuat `AkunPremium`, `1` membuat `AkunTabungan`, selain itu `Akun`.

  Output harus tepat sepuluh baris: `Pemilik`, `Nomor`, `Jenis`, `Nomor Valid`, `Biaya Admin`, `Batas Tarik`, `Tarik Berhasil`, `Sisa Saldo`, `Is Tabungan`, dan `Total Akun`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - Biaya admin berturut-turut 5000, 7000, dan 0.
  - Batas tarik berturut-turut 500000, 1000000, dan 5000000.
  - `tarik` memakai `self.batas_tarik()`, bukan angka yang ditulis langsung.
  - `Is Tabungan` bernilai `True` untuk `AkunPremium` karena premium adalah turunan tabungan.
