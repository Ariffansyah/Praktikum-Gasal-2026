  Tugas

  Lengkapi hierarki peserta pelatihan tiga tingkat. Biaya dan syarat jam disusun bertingkat, dan kelulusan ditentukan melalui method yang dioverride.

  1. Tujuan tugas

  Terapkan inheritance, `super()`, method overriding bertingkat, multilevel inheritance, factory method, dan static method.

  2. Spesifikasi class `Peserta` (parent)

  - `total_peserta = 0` adalah class attribute. Setiap object baru menambahnya satu kali melalui nama class.
  - Constructor menerima `(nama, kode)` dan set `jam` awal `0`.
  - `@classmethod dari_teks(cls, teks)` menerima bagian yang dipisah koma, mengubah underscore menjadi spasi, lalu membuat object melalui `cls(*bagian)`.
  - `@staticmethod kode_valid(kode)` mengembalikan `True` jika panjang kode tepat 7, dua karakter pertama adalah `"PL"`, dan sisa karakternya berupa digit.
  - `mode()` mengembalikan `"Peserta"`, `biaya()` mengembalikan `100000`, `syarat_jam()` mengembalikan `20`.
  - `hadir(jam)` menerima jika jam lebih dari nol, lalu menambah `self.jam`.
  - `lulus()` mengembalikan `True` jika `jam` sudah mencapai hasil `self.syarat_jam()`. Karena syarat diambil melalui method, aturan child otomatis berlaku.

  3. Spesifikasi class `PesertaOnline` (child dari `Peserta`)

  - `mode()` dioverride menjadi `"Peserta Online"`.
  - `biaya()` dioverride. Ambil `super().biaya()` lalu kurangi `40000`.
  - `syarat_jam()` dioverride. Ambil `super().syarat_jam()` lalu tambahkan `4`.

  4. Spesifikasi class `PesertaOnlineBersertifikat` (child dari `PesertaOnline`)

  - `mode()` dioverride menjadi `"Peserta Online Bersertifikat"`.
  - `biaya()` dioverride. Ambil `super().biaya()` lalu tambahkan `150000`. Perhatikan bahwa `super()` di sini menuju `PesertaOnline`, sehingga pengurangan pada tingkat sebelumnya tetap ikut terhitung.
  - `syarat_jam()` dioverride. Ambil `super().syarat_jam()` lalu tambahkan `6`.

  5. Program utama dan output

  Input: `data jam tipe`, dengan `data` berformat `nama,kode`. Nilai `tipe` `2` membuat `PesertaOnlineBersertifikat`, `1` membuat `PesertaOnline`, selain itu `Peserta`.

  Output harus tepat sepuluh baris: `Nama`, `Kode`, `Mode`, `Kode Valid`, `Biaya`, `Syarat Jam`, `Hadir`, `Total Jam`, `Lulus`, dan `Total Peserta`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - Biaya berturut-turut 100000, 60000, dan 210000.
  - Syarat jam berturut-turut 20, 24, dan 30.
  - `lulus()` memakai `self.syarat_jam()`, bukan angka yang ditulis langsung.
  - Kehadiran dengan jam tidak lebih dari nol tidak mengubah `Total Jam`.
