prompt: |
  Tugas

  Lengkapi hierarki pegawai kampus tiga tingkat. Factory method diwarisi oleh seluruh turunan, sehingga penulisan `cls(...)` menjadi penting.

  1. Tujuan tugas

  Terapkan inheritance, `super()`, method overriding bertingkat, multilevel inheritance, factory method, dan static method.

  2. Spesifikasi class `Pegawai` (parent)

  - `total_pegawai = 0` adalah class attribute. Setiap object baru menambahnya satu kali melalui nama class.
  - Constructor menerima `(nama, nip)`.
  - `@classmethod dari_teks(cls, teks)` menerima bagian yang dipisah koma, mengubah underscore pada setiap bagian menjadi spasi, lalu membuat object melalui `cls(*bagian)`. Karena memakai `cls`, method ini tetap benar ketika dipanggil sebagai `Dosen.dari_teks(...)` maupun `GuruBesar.dari_teks(...)`.
  - `@staticmethod nip_valid(nip)` mengembalikan `True` jika panjang `nip` tepat 19 karakter dan seluruhnya digit.
  - `jabatan()` mengembalikan `"Pegawai"`, `tunjangan()` mengembalikan `500000`.
  - `info()` mengembalikan `"<nama> - <hasil jabatan()>"` dan memanggil `self.jabatan()`, sehingga hasilnya ikut berubah setelah dioverride.

  3. Spesifikasi class `Dosen` (child dari `Pegawai`)

  - `batas_sks = 16` adalah class attribute.
  - Constructor menerima `(nama, nip, matkul)`. Gunakan `super().__init__(...)` untuk dua atribut pertama, lalu simpan `matkul` dan set `sks` awal `0`.
  - `jabatan()` dioverride menjadi `"Dosen"`.
  - `tunjangan()` dioverride. Ambil `super().tunjangan()` lalu tambahkan `1500000`.
  - `tambah_sks(jumlah)` menerima jika jumlah lebih dari nol dan `sks + jumlah` tidak melebihi `batas_sks`.

  4. Spesifikasi class `GuruBesar` (child dari `Dosen`)

  - Tidak menuliskan constructor sendiri, sehingga constructor `Dosen` dipakai apa adanya.
  - `jabatan()` dioverride menjadi `"Guru Besar"`.
  - `tunjangan()` dioverride. Ambil `super().tunjangan()` lalu tambahkan `2500000`. Karena `super()` di sini menuju `Dosen`, total tunjangan tersusun bertingkat.

  5. Program utama dan output

  Input: `data sks guru_besar`, dengan `data` berformat `nama,nip,matkul`. Jika `guru_besar` bernilai `1`, object dibuat melalui `GuruBesar.dari_teks(data)`. Selain itu melalui `Dosen.dari_teks(data)`.

  Output harus tepat sepuluh baris: `Nama`, `NIP`, `Matkul`, `Jabatan`, `Info`, `NIP Valid`, `Tunjangan`, `Tambah SKS`, `Total SKS`, dan `Total Pegawai`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - Tunjangan `Dosen` bernilai 2000000 dan `GuruBesar` bernilai 4500000.
  - `dari_teks` menghasilkan object `Dosen` atau `GuruBesar` sesuai class yang memanggilnya.
  - `info()` ikut berubah mengikuti `jabatan()` yang dioverride.
  - `GuruBesar` tetap dapat memakai `tambah_sks` milik `Dosen`.
