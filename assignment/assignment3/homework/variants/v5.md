prompt: |
  Tugas

  Lengkapi hierarki keanggotaan perpustakaan. Satu parent memiliki dua child dengan aturan batas pinjam dan denda yang berbeda.

  1. Tujuan tugas

  Terapkan inheritance, hierarchical inheritance, method overriding, `super()` pada method, factory method, dan static method.

  2. Spesifikasi class `Anggota` (parent)

  - `total_anggota = 0` adalah class attribute. Setiap object baru menambahnya satu kali melalui nama class.
  - Constructor menerima `(nama, kode)` dan set `dipinjam` awal `0`.
  - `@classmethod dari_teks(cls, teks)` menerima bagian yang dipisah koma, mengubah underscore menjadi spasi, lalu membuat object melalui `cls(*bagian)`.
  - `@staticmethod kode_valid(kode)` mengembalikan `True` jika panjang kode tepat 6, karakter pertama adalah `"A"`, dan sisa karakternya berupa digit.
  - `kategori()` mengembalikan `"Anggota"`, `batas_pinjam()` mengembalikan `2`, `denda_per_hari()` mengembalikan `1000`.
  - `kartu()` mengembalikan `"<kode> - <hasil kategori()>"` dan memanggil `self.kategori()`.
  - `pinjam(jumlah)` menerima jika jumlah lebih dari nol dan `dipinjam + jumlah` tidak melebihi hasil `self.batas_pinjam()`. Perhatikan bahwa batas diambil melalui method, bukan angka tetap, sehingga aturan child otomatis berlaku.

  3. Spesifikasi class `AnggotaMahasiswa` (child dari `Anggota`)

  - `kategori()` dioverride menjadi `"Anggota Mahasiswa"`.
  - `batas_pinjam()` dioverride. Ambil `super().batas_pinjam()` lalu tambahkan `3`.
  - `denda_per_hari()` dioverride. Ambil `super().denda_per_hari()` lalu tambahkan `500`.

  4. Spesifikasi class `AnggotaDosen` (child dari `Anggota`)

  - `kategori()` dioverride menjadi `"Anggota Dosen"`.
  - `batas_pinjam()` dioverride. Ambil `super().batas_pinjam()` lalu tambahkan `8`.
  - `denda_per_hari()` dioverride. Ambil `super().denda_per_hari()` lalu kurangi `500`.

  5. Program utama dan output

  Input: `data jumlah hari tipe`, dengan `data` berformat `nama,kode`. Nilai `tipe` `2` membuat `AnggotaDosen`, `1` membuat `AnggotaMahasiswa`, selain itu `Anggota`. Nilai `hari` dipakai untuk menghitung total denda.

  Output harus tepat sepuluh baris: `Nama`, `Kode`, `Kategori`, `Kartu`, `Kode Valid`, `Batas Pinjam`, `Pinjam Berhasil`, `Total Dipinjam`, `Total Denda`, dan `Total Anggota`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - Batas pinjam berturut-turut 2, 5, dan 10.
  - Denda per hari berturut-turut 1000, 1500, dan 500.
  - `pinjam` memakai `self.batas_pinjam()`, bukan angka yang ditulis langsung.
  - `kartu()` ikut berubah mengikuti `kategori()` yang dioverride.
