prompt: |
  Tugas

  Lengkapi hierarki kendaraan operasional kampus. Biaya per kilometer disusun bertingkat, dan `MobilListrik` menambahkan pemeriksaan sendiri sebelum menyerahkan sisanya ke parent.

  1. Tujuan tugas

  Terapkan inheritance, `super()`, method overriding bertingkat, multilevel inheritance, factory method, dan static method.

  2. Spesifikasi class `Kendaraan` (parent)

  - `total_kendaraan = 0` adalah class attribute. Setiap object baru menambahnya satu kali melalui nama class.
  - Constructor menerima `(merk, plat)` dan set `jarak` awal `0`.
  - `@classmethod dari_teks(cls, teks)` menerima bagian yang dipisah koma, mengubah underscore menjadi spasi, lalu membuat object melalui `cls(*bagian)`.
  - `@staticmethod plat_valid(plat)` mengembalikan `True` jika panjang plat minimal 4, karakter pertama berupa huruf, dan sisa karakternya berupa digit.
  - `jenis()` mengembalikan `"Kendaraan"`, `biaya_per_km()` mengembalikan `1000`.
  - `tempuh(km)` menerima jika `km` lebih dari nol, lalu menambah `jarak`.
  - `total_biaya()` mengembalikan `jarak` dikali hasil `self.biaya_per_km()`, sehingga ikut berubah setelah `biaya_per_km()` dioverride.

  3. Spesifikasi class `Mobil` (child dari `Kendaraan`)

  - Constructor menerima `(merk, plat, jumlah_pintu)`. Gunakan `super().__init__(...)` untuk dua atribut pertama, lalu simpan `jumlah_pintu` sebagai integer.
  - `jenis()` dioverride menjadi `"Mobil"`.
  - `biaya_per_km()` dioverride. Ambil `super().biaya_per_km()` lalu tambahkan `1500`.

  4. Spesifikasi class `MobilListrik` (child dari `Mobil`)

  - `batas_km = 300` adalah class attribute. Class ini tidak menuliskan constructor sendiri.
  - `jenis()` dioverride menjadi `"Mobil Listrik"`.
  - `biaya_per_km()` dioverride. Ambil `super().biaya_per_km()` lalu kurangi `2000`. Override tidak selalu menambah nilai.
  - `tempuh(km)` dioverride. Tolak jika `jarak + km` melebihi `batas_km`. Selain itu jangan menulis ulang aturan parent, tetapi kembalikan hasil `super().tempuh(km)` supaya pemeriksaan `km` lebih dari nol tetap berlaku.

  5. Program utama dan output

  Input: `data km listrik`, dengan `data` berformat `merk,plat,jumlah_pintu`. Jika `listrik` bernilai `1`, object dibuat melalui `MobilListrik.dari_teks(data)`. Selain itu melalui `Mobil.dari_teks(data)`.

  Output harus tepat sepuluh baris: `Merk`, `Plat`, `Jumlah Pintu`, `Jenis`, `Plat Valid`, `Biaya per KM`, `Tempuh`, `Total Jarak`, `Total Biaya`, dan `Total Kendaraan`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - Biaya `Mobil` bernilai 2500 dan `MobilListrik` bernilai 500.
  - `MobilListrik.tempuh` tetap memanggil `super().tempuh(km)`, bukan menyalin isi method parent.
  - `total_biaya()` mengikuti biaya per km milik class yang sebenarnya.
  - Operasi `tempuh` yang ditolak tidak mengubah `jarak`.
