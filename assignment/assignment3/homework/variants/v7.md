prompt: |
  Tugas

  Lengkapi hierarki produk koperasi kampus. Satu child hanya mengubah biaya kirim, sedangkan child lainnya mengganti seluruh aturan penjualan.

  1. Tujuan tugas

  Terapkan inheritance, hierarchical inheritance, override tambahan dengan `super()`, override penuh tanpa `super()`, factory method, dan static method.

  2. Spesifikasi class `Produk` (parent)

  - `total_produk = 0` adalah class attribute. Setiap object baru menambahnya satu kali melalui nama class.
  - Constructor menerima `(nama, kode, harga, stok)`. Simpan `harga` dan `stok` sebagai integer, lalu set `terjual` awal `0`.
  - `@classmethod dari_teks(cls, teks)` menerima bagian yang dipisah koma, mengubah underscore menjadi spasi, lalu membuat object melalui `cls(*bagian)`.
  - `@staticmethod kode_valid(kode)` mengembalikan `True` jika panjang kode tepat 5, karakter pertama adalah `"P"`, dan sisanya berupa digit.
  - `kategori()` mengembalikan `"Produk"`, `biaya_kirim()` mengembalikan `10000`.
  - `harga_total(jumlah)` mengembalikan `harga` dikali `jumlah` ditambah hasil `self.biaya_kirim()`.
  - `jual(jumlah)` menerima jika jumlah lebih dari nol dan tidak melebihi `stok`. Jika diterima, kurangi `stok` dan tambah `terjual`.

  3. Spesifikasi class `ProdukFisik` (child dari `Produk`)

  - `kategori()` dioverride menjadi `"Produk Fisik"`.
  - `biaya_kirim()` dioverride. Ambil `super().biaya_kirim()` lalu tambahkan `5000`.
  - `jual()` tidak dioverride, sehingga aturan stok milik parent tetap berlaku.

  4. Spesifikasi class `ProdukDigital` (child dari `Produk`)

  - `kategori()` dioverride menjadi `"Produk Digital"`.
  - `biaya_kirim()` dioverride. Ambil `super().biaya_kirim()` lalu kurangi `10000`, sehingga hasilnya nol.
  - `jual(jumlah)` dioverride penuh tanpa `super()`. Produk digital tidak memiliki batas stok, sehingga method ini hanya menolak jumlah yang tidak lebih dari nol, lalu menambah `terjual` tanpa mengubah `stok`. Inilah contoh override yang mengganti seluruh perilaku parent, bukan menambahnya.

  5. Program utama dan output

  Input: `data jumlah tipe`, dengan `data` berformat `nama,kode,harga,stok`. Nilai `tipe` `2` membuat `ProdukDigital`, `1` membuat `ProdukFisik`, selain itu `Produk`.

  Output harus tepat sepuluh baris: `Nama`, `Kode`, `Kategori`, `Kode Valid`, `Biaya Kirim`, `Jual Berhasil`, `Sisa Stok`, `Terjual`, `Harga Total`, dan `Total Produk`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - Biaya kirim berturut-turut 10000, 15000, dan 0.
  - `ProdukDigital` tetap berhasil menjual meskipun jumlah melebihi stok.
  - `Sisa Stok` pada `ProdukDigital` tidak pernah berubah.
  - `harga_total` memakai `self.biaya_kirim()` sehingga mengikuti class yang sebenarnya.
