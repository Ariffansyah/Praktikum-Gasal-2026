  Tugas

  Lengkapi sistem karakter game. `Paladin` dibentuk dari `Warrior` dan `MagicUser` yang sama-sama merupakan turunan `Karakter`, sehingga membentuk susunan diamond.

  1. Tujuan tugas

  Terapkan inheritance, multiple inheritance, diamond problem, MRO, method overriding, dan static method.

  2. Spesifikasi class `Karakter` (parent)

  - `total_karakter = 0` adalah class attribute. Setiap kali constructor `Karakter` dijalankan, nilainya bertambah satu melalui nama class.
  - Constructor menerima `(nama, hp)`.
  - `@staticmethod hp_valid(hp)` mengembalikan `True` jika `hp` lebih dari `0` dan tidak lebih dari `500`.
  - `kelas()` mengembalikan `"Karakter"`.
  - `status()` mengembalikan `"<nama> | HP <hp> | <hasil kelas()>"` dan memanggil `self.kelas()`.
  - `terkena_serangan(damage)` menolak jika damage tidak lebih dari nol. Jika diterima, kurangi `hp` tetapi jangan sampai kurang dari nol, lalu kembalikan `True`.

  3. Spesifikasi class `Warrior` dan `MagicUser` (child dari `Karakter`)

  - `Warrior` menerima `(nama, hp, kekuatan)`, `MagicUser` menerima `(nama, hp, mana)`.
  - Kedua constructor memanggil `Karakter.__init__(self, nama, hp)` secara langsung melalui nama class, bukan melalui `super()`. Alasannya dijelaskan pada poin 4.
  - `kelas()` dioverride menjadi `"Warrior"` dan `"MagicUser"`.
  - `Warrior.serang()` mengembalikan `kekuatan` dikali `2`. `MagicUser.sihir()` mengembalikan `mana` dikali `3`.

  4. Spesifikasi class `Paladin(Warrior, MagicUser)`

  - Constructor menerima `(nama, hp, kekuatan, mana)` dan memanggil `Warrior.__init__(self, ...)` lalu `MagicUser.__init__(self, ...)` secara langsung.
  - Jika `Warrior` memakai `super().__init__(nama, hp)`, pemanggilan tersebut akan mengikuti MRO milik `Paladin` dan menuju `MagicUser`, bukan `Karakter`. `MagicUser` membutuhkan `mana`, sehingga program akan berhenti dengan `TypeError`. Karena itu soal ini memakai pemanggilan langsung melalui nama class.
  - Akibat pemanggilan langsung tersebut, constructor `Karakter` dijalankan dua kali untuk satu object `Paladin`, sehingga `total_karakter` bernilai `2`. Perilaku ini memang diharapkan pada soal ini.
  - `kelas()` dioverride menjadi `"Paladin"`.
  - `serang()` dioverride. Ambil `super().serang()` yang menuju `Warrior`, lalu tambahkan hasil `self.sihir()` milik `MagicUser`.

  5. Program utama dan output

  Input: `data damage tipe`, dengan `data` berformat `nama,hp,kekuatan,mana`. Nilai `tipe` `2` membuat `Paladin`, `1` membuat `MagicUser`, selain itu `Warrior`. Nilai serangan dihitung sebelum karakter terkena serangan.

  Output harus tepat sepuluh baris: `Nama`, `Kelas`, `Status`, `HP Valid`, `Nilai Serangan`, `Kena Serangan`, `Sisa HP`, `Is Warrior`, `MRO`, dan `Total Karakter`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()` atau pemanggilan constructor parent yang diminta.
  - Method yang dioverride wajib memanggil versi parent jika soal memintanya, bukan menuliskan hasil akhirnya langsung.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh mengubah state.
  - Counter class harus diubah melalui nama class, bukan melalui `self`.
  - Factory method harus membuat object melalui `cls(...)`, bukan menuliskan nama class secara langsung.
  - Static method tidak boleh bergantung pada `self` maupun `cls`.

  Checklist sebelum Run Tests

  - MRO `Paladin` diawali `Paladin > Warrior > MagicUser`.
  - `Total Karakter` bernilai `2` untuk `Paladin` dan `1` untuk dua class lainnya.
  - `Sisa HP` tidak pernah bernilai negatif.
  - `serang()` pada `Paladin` menggabungkan kekuatan dan mana.
