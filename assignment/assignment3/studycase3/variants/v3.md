prompt: |
  Tugas

  Lengkapi hierarki class koleksi perpustakaan. Program utama membuat object `Buku` atau `BukuDigital`, lalu mencoba meminjam sejumlah eksemplar.

  1. Tujuan tugas

  Terapkan inheritance, `super()` pada constructor, method overriding bertingkat, dan multilevel inheritance.

  2. Spesifikasi class `Koleksi` (parent)

  - `total_koleksi = 0` adalah class attribute.
  - Constructor menerima `(judul, tahun)` dan menyimpan keduanya sebagai public attribute.
  - Setiap object baru menambah `total_koleksi` satu kali. Ubah melalui nama class, bukan melalui `self`.
  - `jenis()` mengembalikan `"Koleksi"`.
  - `durasi_pinjam()` mengembalikan `7`.
  - `label()` mengembalikan `"<judul> (<hasil jenis()>)"`. Method ini memanggil `self.jenis()`, sehingga hasilnya ikut berubah ketika `jenis()` dioverride.

  3. Spesifikasi class `Buku` (child dari `Koleksi`)

  - `batas_eksemplar = 5` adalah class attribute.
  - Constructor menerima `(judul, tahun, stok)`. Gunakan `super().__init__(...)` untuk `judul` dan `tahun`, lalu simpan `stok` dan set `dipinjam` awal menjadi `0`.
  - `jenis()` dioverride dan mengembalikan `"Buku"`.
  - `durasi_pinjam()` dioverride. Ambil hasil `super().durasi_pinjam()` lalu tambahkan `7`.
  - `pinjam(jumlah)` mengembalikan `True` jika jumlah lebih dari nol, jumlah tidak melebihi `stok`, dan `dipinjam + jumlah` tidak melebihi `batas_eksemplar`. Jika diterima, kurangi `stok` dan tambah `dipinjam`. Jika ditolak, kembalikan `False` dan jangan mengubah keduanya.

  4. Spesifikasi class `BukuDigital` (child dari `Buku`)

  - Class ini tidak menuliskan constructor sendiri, sehingga constructor `Buku` dipakai apa adanya.
  - `jenis()` dioverride dan mengembalikan `"Buku Digital"`.
  - `durasi_pinjam()` dioverride. Ambil hasil `super().durasi_pinjam()` lalu tambahkan `14`. Perhatikan bahwa `super()` di sini menuju `Buku`, bukan `Koleksi`, sehingga durasi tersusun bertingkat.

  5. Program utama dan output

  Input: `judul tahun stok jumlah digital`. Underscore pada `judul` sudah diubah menjadi spasi oleh program utama. Jika `digital` bernilai `1`, object yang dibuat adalah `BukuDigital`. Selain itu `Buku`.

  Output harus tepat sembilan baris: `Judul`, `Tahun`, `Jenis`, `Label`, `Durasi Pinjam`, `Pinjam Berhasil`, `Sisa Stok`, `Total Dipinjam`, dan `Total Koleksi`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()`.
  - `durasi_pinjam()` pada child wajib memakai `super().durasi_pinjam()`, bukan menuliskan angka totalnya langsung.
  - Operasi `pinjam` yang ditolak tidak boleh mengubah `stok` maupun `dipinjam`.
  - `total_koleksi` tidak boleh dibuat sebagai instance attribute.

  Checklist sebelum Run Tests

  - Durasi `Buku` bernilai 14 dan `BukuDigital` bernilai 28.
  - `label()` ikut berubah mengikuti `jenis()` yang dioverride.
  - Ketiga syarat pada `pinjam` benar-benar diperiksa, termasuk batas eksemplar.
  - `Total Koleksi` tetap `1` karena hanya satu object yang dibuat.
