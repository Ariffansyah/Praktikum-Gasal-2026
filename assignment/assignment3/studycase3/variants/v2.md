  Tugas

  Lengkapi hierarki class pegawai kampus. Program utama membuat object `Dosen` atau `GuruBesar`, lalu mencoba menambah SKS mengajar.

  1. Tujuan tugas

  Terapkan inheritance, `super()` pada constructor, method overriding bertingkat, dan multilevel inheritance.

  2. Spesifikasi class `Pegawai` (parent)

  - `total_pegawai = 0` adalah class attribute.
  - Constructor menerima `(nama, nip)` dan menyimpan keduanya sebagai public attribute.
  - Setiap object baru menambah `total_pegawai` satu kali. Ubah melalui nama class, bukan melalui `self`.
  - `jabatan()` mengembalikan `"Pegawai"`.
  - `gaji_pokok()` mengembalikan `4000000`.
  - `info()` mengembalikan `"<nama> sebagai <hasil jabatan()>"`. Method ini memanggil `self.jabatan()`, sehingga hasilnya ikut berubah ketika `jabatan()` dioverride.

  3. Spesifikasi class `Dosen` (child dari `Pegawai`)

  - `batas_sks = 16` adalah class attribute.
  - Constructor menerima `(nama, nip, matkul)`. Gunakan `super().__init__(...)` untuk `nama` dan `nip`, lalu simpan `matkul` dan set `sks_mengajar` awal menjadi `0`.
  - `jabatan()` dioverride dan mengembalikan `"Dosen"`.
  - `gaji_pokok()` dioverride. Ambil hasil `super().gaji_pokok()` lalu tambahkan `2000000`.
  - `tambah_sks(jumlah)` mengembalikan `True` jika jumlah lebih dari nol dan `sks_mengajar + jumlah` tidak melebihi `batas_sks`. Jika ditolak, kembalikan `False` dan jangan mengubah `sks_mengajar`.

  4. Spesifikasi class `GuruBesar` (child dari `Dosen`)

  - Class ini tidak menuliskan constructor sendiri, sehingga constructor `Dosen` dipakai apa adanya.
  - `jabatan()` dioverride dan mengembalikan `"Guru Besar"`.
  - `gaji_pokok()` dioverride. Ambil hasil `super().gaji_pokok()` lalu tambahkan `3000000`. Perhatikan bahwa `super()` di sini menuju `Dosen`, bukan `Pegawai`, sehingga gaji tersusun bertingkat.

  5. Program utama dan output

  Input: `nama nip matkul sks guru_besar`. Underscore pada `nama` dan `matkul` sudah diubah menjadi spasi oleh program utama. Jika `guru_besar` bernilai `1`, object yang dibuat adalah `GuruBesar`. Selain itu `Dosen`.

  Output harus tepat sembilan baris: `Nama`, `NIP`, `Matkul`, `Jabatan`, `Info`, `Gaji Pokok`, `Tambah SKS`, `Total SKS`, dan `Total Pegawai`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()`.
  - `gaji_pokok()` pada child wajib memakai `super().gaji_pokok()`, bukan menuliskan angka totalnya langsung.
  - Operasi `tambah_sks` yang ditolak tidak boleh mengubah `sks_mengajar`.
  - `total_pegawai` tidak boleh dibuat sebagai instance attribute.

  Checklist sebelum Run Tests

  - Gaji `Dosen` bernilai 6000000 dan `GuruBesar` bernilai 9000000.
  - `info()` ikut berubah mengikuti `jabatan()` yang dioverride.
  - `GuruBesar` tetap dapat memakai `tambah_sks` milik `Dosen`.
  - `Total Pegawai` tetap `1` karena hanya satu object yang dibuat.
