prompt: |
  Setelah mengembangkan toko online miliknya, Mas Obie memiliki berbagai jenis barang dan produk digital. Agar program lebih mudah dikelola, Mas Obie ingin menggunakan inheritance untuk menghindari penulisan atribut dan method yang sama berulang kali.

  Beberapa jenis produk memiliki informasi umum yang sama, tetapi memiliki karakteristik khusus masing-masing. Beberapa produk juga merupakan pengembangan dari class yang sudah diwarisi sebelumnya. Selain itu, terdapat produk yang memiliki kemampuan tambahan berupa
  promo.

  Sebagai teman baik Mas Obie, bantu implementasikan struktur class tersebut dengan menerapkan inheritance, parent/base class, child/derived class, method overriding, nested/multilevel inheritance, dan multiple inheritance.

  1. Tujuan Tugas

  Terapkan konsep berikut:

  - Parent/Base Class
  - Child/Derived Class
  - Inheritance
  - `super()` pada constructor
  - Method overriding
  - Nested/Multilevel inheritance
  - Multiple inheritance

  Dengan demikian:

  - `ProdukFisik` dan `ProdukDigital` merupakan child dari `ItemToko`.
  - `Aplikasi` merupakan child dari `ProdukDigital`, sehingga membentuk nested/multilevel
    inheritance.
  - `ProdukPromo` mewarisi `ProdukDigital` dan `Promo`, sehingga menerapkan multiple
    inheritance.

  2. Spesifikasi Class `ItemToko` (Parent/Base Class)

  Class `ItemToko` merupakan parent class yang menyimpan informasi umum seluruh item toko.

  - Constructor menerima `(nama, harga)`.
  - Simpan `nama` sebagai public attribute.
  - Simpan `harga` sebagai public attribute.
  - Method `info()` mengembalikan: <nama> - Rp<harga>
  - Method `hitung_total(jumlah)` mengembalikan: harga * jumlah

  3. Spesifikasi Class `ProdukFisik` (Child)

  `ProdukFisik` merupakan child dari `ItemToko`.

  - Constructor menerima `(nama, harga, berat)`.
  - Gunakan `super().__init__(...)` untuk menginisialisasi `nama` dan `harga`.
  - Simpan `berat` sebagai public attribute.
  - Override method `info()`.
  - Pada method `info()`, jalankan `super().info()` terlebih dahulu.
  - Tambahkan informasi berat dengan format: <hasil super>, produk fisik, berat <berat> kg

  4. Spesifikasi Class `ProdukDigital` (Child)

  `ProdukDigital` merupakan child dari `ItemToko`.

  - Constructor menerima `(nama, harga, ukuran)`.
  - Gunakan `super().__init__(...)` untuk menginisialisasi `nama` dan `harga`.
  - Simpan `ukuran` sebagai public attribute.
  - Ukuran dinyatakan dalam MB.
  - Override method `info()`.
  - Jalankan `super().info()` terlebih dahulu.
  - Tambahkan informasi ukuran dengan format: <hasil super>, produk digital, ukuran <ukuran> MB

  5. Spesifikasi Class `Aplikasi` (Nested/Multilevel Inheritance)

  `Aplikasi` merupakan child dari `ProdukDigital`.

  Dengan demikian terbentuk inheritance bertingkat:

  ItemToko
      ↓
  ProdukDigital
      ↓
  Aplikasi


  Ketentuan:

  - Constructor menerima `(nama, harga, ukuran, versi)`.
  - Gunakan `super().__init__(...)` untuk memanggil constructor `ProdukDigital`.
  - Simpan `versi` sebagai public attribute.
  - Override method `info()`.
  - Jalankan `super().info()` terlebih dahulu.
  - Tambahkan informasi versi dengan format: <hasil super>, versi <versi>

  6. Spesifikasi Class `Promo` (Parent Tambahan)

  `Promo` merupakan class yang menyediakan kemampuan tambahan berupa perhitungan harga
  setelah diskon.

  - Constructor menerima `(persen)`.
  - Simpan `persen` sebagai public attribute.
  - Method `harga_setelah_promo()` menghitung harga setelah diskon berdasarkan atribut
    `harga` yang dimiliki object.

  Rumus: harga setelah promo = harga - (harga * persen / 100)

  Untuk perhitungan program, gunakan operasi integer: harga - (harga * persen // 100)

  7. Spesifikasi Class `ProdukPromo` (Multiple Inheritance)

  `ProdukPromo` merupakan class yang memiliki dua parent yaitu `ProdukDigital` dan `Promo` 

  Dengan demikian `ProdukPromo` mendapatkan:

  - atribut dan method dari `ProdukDigital`;
  - atribut dan method dari `ItemToko` melalui `ProdukDigital`;
  - kemampuan promo dari `Promo`.

  Ketentuan:

  - Constructor menerima `(nama, harga, ukuran, persen)`.
  - Inisialisasi bagian `ProdukDigital`.
  - Inisialisasi bagian `Promo`.
  - Override method `info()`.
  - Gunakan `super().info()` untuk mendapatkan informasi produk digital.
  - Tambahkan informasi promo dengan format: <hasil super>, diskon <persen>%
  - Method `harga_setelah_promo()` harus dapat digunakan oleh object `ProdukPromo`.

  8. Program Utama dan Input

  Program utama menerima input: nama harga jumlah jenis detail tambahan persen

  Keterangan:

  - `nama` adalah nama produk. Underscore `_` akan diubah menjadi spasi.
  - `harga` adalah harga produk.
  - `jumlah` adalah jumlah item yang dibeli.
  - `jenis` menentukan object yang dibuat:
    - `1` → `ProdukFisik`
    - `2` → `ProdukDigital`
    - `3` → `Aplikasi`
    - `4` → `ProdukPromo`
  - `detail` digunakan sebagai:
    - berat untuk `ProdukFisik`;
    - ukuran MB untuk `ProdukDigital`;
    - ukuran MB untuk `Aplikasi` dan `ProdukPromo`.
  - `tambahan` digunakan sebagai versi untuk `Aplikasi`.
    Underscore `_` akan diubah menjadi spasi.
  - `persen` digunakan sebagai persentase promo untuk `ProdukPromo`.
  - Untuk jenis yang tidak menggunakan suatu field, nilainya tetap diberikan oleh input
    tetapi tidak perlu digunakan.

  9. Output

  Output harus tepat sembilan baris:

  Nama
  Harga
  Jenis
  Info
  Total Harga
  Harga Setelah Promo
  Is Item Toko
  Is Produk Digital
  Is Aplikasi

  Untuk produk yang bukan `ProdukPromo`, `Harga Setelah Promo` harus menampilkan: -


  `isinstance()` digunakan untuk memeriksa hubungan inheritance.

  10. Aturan

  - Lengkapi bagian `TODO` saja.
  - Jangan mengubah program utama.
  - Jangan mengubah nama class.
  - Jangan mengubah signature constructor dan method.
  - Jangan mengubah label atau urutan output.
  - Gunakan `super()` pada constructor child.
  - Method `info()` pada child wajib melakukan overriding.
  - Pada overriding `info()`, gunakan `super().info()` terlebih dahulu.
  - `Aplikasi` wajib mewarisi `ProdukDigital`.
  - `ProdukPromo` wajib memiliki dua parent: `ProdukDigital` dan `Promo`.
  - Jangan menulis ulang atribut `nama` dan `harga` pada child.
  - `ProdukPromo` harus tetap dapat menggunakan method `hitung_total()` dari `ItemToko`.
  - `ProdukPromo` harus tetap dapat menggunakan method `harga_setelah_promo()` dari `Promo`.

  Checklist sebelum Run Tests

  - `ProdukFisik` merupakan child dari `ItemToko`.
  - `ProdukDigital` merupakan child dari `ItemToko`.
  - `Aplikasi` merupakan child dari `ProdukDigital`.
  - `ProdukPromo` memiliki dua parent.
  - Constructor child menggunakan `super()`.
  - `info()` dioverride pada class turunan.
  - `super().info()` digunakan ketika melakukan overriding.
  - Object `Aplikasi` dapat menggunakan method milik `ProdukDigital` dan `ItemToko`.
  - Object `ProdukPromo` dapat menggunakan method dari `ProdukDigital`, `ItemToko`,
    dan `Promo`.
  - Perhitungan total harga tidak mengubah harga satuan.
  - Promo hanya diterapkan pada `ProdukPromo`.
