prompt: |
  Tugas

  Lengkapi hierarki class sivitas akademika. Program utama membuat object `Mahasiswa` atau `AsistenPraktikum`, lalu mencoba menambah SKS.

  1. Tujuan tugas

  Terapkan inheritance, `super()` pada constructor, method overriding, dan multilevel inheritance.

  2. Spesifikasi class `User` (parent)

  - `total_user = 0` adalah class attribute.
  - Constructor menerima `(nama, email)` dan menyimpan keduanya sebagai public attribute.
  - Setiap object baru menambah `total_user` satu kali. Ubah melalui nama class, bukan melalui `self`.
  - `peran()` mengembalikan `"User"`.
  - `sapa()` mengembalikan `"Halo, <nama>"`.

  3. Spesifikasi class `Mahasiswa` (child dari `User`)

  - `batas_sks = 24` adalah class attribute.
  - Constructor menerima `(nama, email, nim)`. Gunakan `super().__init__(...)` untuk mengisi `nama` dan `email`, lalu simpan `nim` dan set `sks` awal menjadi `0`.
  - `peran()` dioverride dan mengembalikan `"Mahasiswa"`.
  - `sapa()` dioverride. Jalankan `super().sapa()` lebih dahulu, lalu kembalikan `"<hasil super>, mahasiswa dengan NIM <nim>"`.
  - `ambil_sks(jumlah)` mengembalikan `True` jika jumlah lebih dari nol dan `sks + jumlah` tidak melebihi `batas_sks`. Jika diterima, tambahkan ke `sks`. Jika ditolak, kembalikan `False` dan jangan mengubah `sks`.

  4. Spesifikasi class `AsistenPraktikum` (child dari `Mahasiswa`)

  - Constructor menerima `(nama, email, nim, matkul)`. Gunakan `super().__init__(...)` untuk tiga atribut pertama, lalu simpan `matkul`.
  - `peran()` dioverride dan mengembalikan `"Asisten Praktikum"`.
  - `sapa()` dioverride. Jalankan `super().sapa()` lebih dahulu, lalu kembalikan `"<hasil super>, asisten <matkul>"`.

  5. Program utama dan output

  Input: `nama email nim matkul sks asisten`. Underscore pada `nama` dan `matkul` sudah diubah menjadi spasi oleh program utama. Jika `asisten` bernilai `1`, object yang dibuat adalah `AsistenPraktikum`. Selain itu `Mahasiswa`.

  Output harus tepat sembilan baris: `Nama`, `Email`, `NIM`, `Peran`, `Sapa`, `Ambil SKS`, `Total SKS`, `Total User`, dan `Is Mahasiswa`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Jangan menulis ulang atribut parent di child. Gunakan `super()`.
  - `sapa()` pada child wajib memakai `super().sapa()`, bukan menyusun ulang teks parent dari awal.
  - Operasi `ambil_sks` yang ditolak tidak boleh mengubah nilai `sks`.
  - `total_user` tidak boleh dibuat sebagai instance attribute.

  Checklist sebelum Run Tests

  - Setiap constructor child memanggil `super().__init__(...)`.
  - `peran()` menghasilkan teks berbeda untuk tiap tingkat.
  - `sapa()` pada `AsistenPraktikum` memuat sapaan `User` dan `Mahasiswa` sekaligus.
  - `Total User` tetap `1` karena hanya satu object yang dibuat.
