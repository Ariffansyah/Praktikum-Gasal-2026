  Tugas: Pengumuman dan Subpackage Formatter

  Susun package a6_pengumuman agar aturan perhitungan, service, formatter, dan CLI dapat digunakan secara terpisah. Isi setiap file berada dalam dictionary FILES pada starter. Ubah hanya komentar TODO di dalam string file yang bersangkutan; jangan mengganti nama file, harness, data class, input adapter, contoh, atau unit test yang diberikan.

  1. Struktur dan tanggung jawab

  - `a6_pengumuman/models.py`: data dan model.
  - `a6_pengumuman/input_adapter.py`: parser input yang sudah diberikan.
  - `a6_pengumuman/rules.py`: helper atau subpackage yang diberikan.
  - `a6_pengumuman/templates.py`: helper atau subpackage yang diberikan.
  - `a6_pengumuman/formatters/teks.py`: helper atau subpackage yang diberikan.
  - `a6_pengumuman/formatters/csv.py`: helper atau subpackage yang diberikan.
  - `a6_pengumuman/services.py`: service aplikasi.
  - `a6_pengumuman/formatters/__init__.py`: formatter tampilan.
  - `a6_pengumuman/cli.py`: stdin/stdout dan main guard.
  - `a6_pengumuman/__init__.py`: public API/regular package.
  - `a6_pengumuman/__main__.py`: entry point package.

  2. Kontrak khusus varian

  - rules.cocok(kelas, target) dan templates.bangun(nama, pesan) sudah disediakan. Target '-' berarti seluruh kelas.
  - buat_pesan(data, opsi) memakai kedua helper itu untuk memilih penerima dan membuat PesanJadi dalam urutan input. Service tidak memilih format tampilan.
  - formatters adalah SUBPACKAGE, bukan formatters.py. Lengkapi formatters/__init__.py agar mengimpor format_baris dari teks.py/csv.py dengan alias format_teks/format_csv.
  - format_hasil(hasil, opsi) memilih helper sesuai opsi['gaya'] lalu mengembalikan list string. Teks: nim | isi. CSV: nim;isi. Helper formatter sudah diberikan; tidak perlu menulis ulang bentuk barisnya.
  - Public API adalah buat_pesan dan Penerima. Impor formatter pada CLI tetap melalui .formatters.
  - Jangan mengirim pesan jaringan, mencetak dari service, atau mengubah data sumber. Lengkapi wiring dan kedua main guard.

  3. Aturan modularisasi

  - Public API harus mengekspor `buat_pesan` dari `services.py` dan `Penerima` dari `models.py`. Jangan membuat wrapper baru pada __init__.py atau menyalin definisi function/class ke file lain.
  - Gunakan import dan alias sesuai kontrak; helper dan model tidak mengimpor CLI. `input_adapter.py` dan isi `main()` CLI sudah disediakan.
  - Lengkapi main guard pada `cli.py` dan `__main__.py`. Import normal tidak menjalankan aplikasi, membaca stdin, atau mencetak laporan.
  - Service menerima data/opsi, mengembalikan LIST BARU hasil setiap pemanggilan, dan tidak mengubah data maupun opsi. Formatter mengembalikan list string; hanya CLI yang mencetak.
  - Semua contoh memakai Python standard library. Jangan memasang dependency tambahan, memodifikasi sys.path di file aplikasi, atau menghapus pemisahan module untuk mengejar output.

  4. Format input

  n (0..20); n baris nim nama kelas dengan NIM unik; terakhir target gaya pesan. Target '-' atau salah satu 2025A/B/C, gaya teks/csv. Nama dan pesan menggunakan underscore untuk spasi. Tidak ada karakter semicolon atau tanda petik pada data.

  5. Hasil aplikasi dan pemeriksaan

  CLI menampilkan satu baris per penerima yang cocok, sesuai urutan input. Template isi adalah nama: pesan; bentuk akhir dipilih pada subpackage formatter.

  Harness mencetak 10 label. Import Tenang dan Layanan Tenang harus True. API harus `a6_pengumuman.services`; Model API harus True. Layanan dan Ulang adalah list hasil formatter untuk dua pemanggilan service. Data Tetap memeriksa data beserta opsi; List Baru memastikan hasil service tidak dipakai ulang. CLI dan Package berisi hasil menjalankan module CLI dan entry point package dengan input yang sama. Keduanya harus sama dengan Layanan.

  Gunakan Run Tests karena Run tidak menyediakan input otomatis. Program yang belum lengkap dapat menghasilkan ImportError, AttributeError, atau NameError sampai seluruh TODO terkait selesai.

  6. Ekspor dan pengujian lokal

  - Unduh jawaban.py setelah seluruh test browser lulus.
  - Jalankan `python jawaban.py --export folder_baru` untuk membuat folder proyek yang belum ada. Ekspor tidak menimpa folder yang sudah ada.
  - Dari folder hasil ekspor, jalankan `Get-Content contoh_input.txt | python -m a6_pengumuman` pada PowerShell.
  - Jalankan `python -m unittest discover -s tests -v`; tiga unit test yang disediakan harus lulus.
  - Ikuti arahan pengajar untuk mengumpulkan bundle Python dan/atau folder proyek. Save File tidak otomatis mengirim jawaban.

  PACKAGE = 'a6_pengumuman'
  API = 'buat_pesan'
  MODEL = 'Penerima'

  from contextlib import redirect_stdout
  from io import StringIO
  from pathlib import Path
  from tempfile import TemporaryDirectory
  import copy
  import importlib
  import runpy
  import sys


  def tulis_proyek(root):
      for name, source in FILES.items():
          relatif = Path(name)
          if relatif.is_absolute() or '..' in relatif.parts:
              raise ValueError('Nama file harus relatif di dalam proyek')
          path = root / relatif
          path.parent.mkdir(parents=True, exist_ok=True)
          path.write_text(source, encoding='utf-8')


  def bersihkan_package():
      for name in list(sys.modules):
          if name == PACKAGE or name.startswith(PACKAGE + '.'):
              sys.modules.pop(name, None)


  def jalankan_module(nama, teks):
      sebelumnya = sys.stdin
      output = StringIO()
      try:
          sys.stdin = StringIO(teks)
          with redirect_stdout(output):
              runpy.run_module(nama, run_name='__main__')
      finally:
          sys.stdin = sebelumnya
      return output.getvalue().splitlines()


  def periksa(teks):
      bersihkan_package()
      with TemporaryDirectory() as folder:
          root = Path(folder)
          tulis_proyek(root)
          sys.path.insert(0, folder)
          importlib.invalidate_caches()
          try:
              output_import = StringIO()
              with redirect_stdout(output_import):
                  package = importlib.import_module(PACKAGE)
                  importlib.import_module(PACKAGE + '.cli')
                  models = importlib.import_module(PACKAGE + '.models')
                  adapter = importlib.import_module(PACKAGE + '.input_adapter')
                  formatter = importlib.import_module(PACKAGE + '.formatters')
              api = getattr(package, API)
              model = getattr(models, MODEL)
              data, opsi = adapter.baca(teks)
              sebelum = copy.deepcopy((data, opsi))
              output_layanan = StringIO()
              with redirect_stdout(output_layanan):
                  pertama = api(data, opsi)
                  kedua = api(data, opsi)
                  tampilan1 = formatter.format_hasil(pertama, opsi)
                  tampilan2 = formatter.format_hasil(kedua, opsi)
              print('Import Tenang:', output_import.getvalue() == '')
              print('API:', api.__module__)
              print('Model API:', getattr(package, MODEL) is model and model.__module__ == PACKAGE + '.models')
              print('Layanan Tenang:', output_layanan.getvalue() == '')
              print('Layanan:', tampilan1)
              print('Ulang:', tampilan2)
              print('Data Tetap:', (data, opsi) == sebelum)
              print('List Baru:', isinstance(pertama, list) and isinstance(kedua, list) and pertama is not kedua)
              sys.modules.pop(PACKAGE + '.cli', None)
              print('CLI:', jalankan_module(PACKAGE + '.cli', teks))
              print('Package:', jalankan_module(PACKAGE, teks))
          finally:
              sys.path.remove(folder)
              bersihkan_package()
              importlib.invalidate_caches()

      print('Proyek diekspor ke:', tujuan.resolve())
  else:
      periksa(sys.stdin.read())
