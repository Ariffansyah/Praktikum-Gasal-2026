  Tugas: Inventaris dan Dependency Satu Arah

  Susun package a6_inventaris agar aturan perhitungan, service, formatter, dan CLI dapat digunakan secara terpisah. Isi setiap file berada dalam dictionary FILES pada starter. Ubah hanya komentar TODO di dalam string file yang bersangkutan; jangan mengganti nama file, harness, data class, input adapter, contoh, atau unit test yang diberikan.

  1. Struktur dan tanggung jawab

  - `a6_inventaris/models.py`: data dan model.
  - `a6_inventaris/input_adapter.py`: parser input yang sudah diberikan.
  - `a6_inventaris/rules.py`: helper atau subpackage yang diberikan.
  - `a6_inventaris/services.py`: service aplikasi.
  - `a6_inventaris/formatters.py`: formatter tampilan.
  - `a6_inventaris/cli.py`: stdin/stdout dan main guard.
  - `a6_inventaris/__init__.py`: public API/regular package.
  - `a6_inventaris/__main__.py`: entry point package.

  2. Kontrak khusus varian

  - models.py hanya menyimpan data MutasiStok dan StokAkhir. Model tidak mengimpor CLI atau service.
  - rules.py sudah menyediakan terima(jumlah, minimum), yaitu jumlah >= minimum.
  - rekap_stok(data, opsi): jumlahkan semua perubahan per kode dari saldo awal nol. Kode berulang memang diperbolehkan. Setelah SEMUA mutasi dijumlahkan, filter melalui terima(), lalu urutkan kode menaik dan buat StokAkhir baru.
  - Saldo negatif merupakan hasil sah pada data latihan ini, bukan operasi yang harus ditolak. Minimum dapat negatif.
  - format_hasil: list kode=jumlah. Jangan mencetak dari aturan, model, atau service.
  - Gunakan relative import model dan rule di service. Public API adalah rekap_stok dan MutasiStok; selesaikan wiring CLI serta guard tanpa circular import.

  3. Aturan modularisasi

  - Public API harus mengekspor `rekap_stok` dari `services.py` dan `MutasiStok` dari `models.py`. Jangan membuat wrapper baru pada __init__.py atau menyalin definisi function/class ke file lain.
  - Gunakan import dan alias sesuai kontrak; helper dan model tidak mengimpor CLI. `input_adapter.py` dan isi `main()` CLI sudah disediakan.
  - Lengkapi main guard pada `cli.py` dan `__main__.py`. Import normal tidak menjalankan aplikasi, membaca stdin, atau mencetak laporan.
  - Service menerima data/opsi, mengembalikan LIST BARU hasil setiap pemanggilan, dan tidak mengubah data maupun opsi. Formatter mengembalikan list string; hanya CLI yang mencetak.
  - Semua contoh memakai Python standard library. Jangan memasang dependency tambahan, memodifikasi sys.path di file aplikasi, atau menghapus pemisahan module untuk mengejar output.

  4. Format input

  n (0..20); n baris kode perubahan; baris terakhir minimum. Perubahan adalah integer bertanda, kode boleh berulang dan tidak mengandung spasi. Minimum integer bertanda.

  5. Hasil aplikasi dan pemeriksaan

  CLI mencetak kode=jumlah saldo akhir yang memenuhi minimum, urut kode. Tidak ada pembatasan saldo ke nol.

  Harness mencetak 10 label. Import Tenang dan Layanan Tenang harus True. API harus `a6_inventaris.services`; Model API harus True. Layanan dan Ulang adalah list hasil formatter untuk dua pemanggilan service. Data Tetap memeriksa data beserta opsi; List Baru memastikan hasil service tidak dipakai ulang. CLI dan Package berisi hasil menjalankan module CLI dan entry point package dengan input yang sama. Keduanya harus sama dengan Layanan.

  Gunakan Run Tests karena Run tidak menyediakan input otomatis. Program yang belum lengkap dapat menghasilkan ImportError, AttributeError, atau NameError sampai seluruh TODO terkait selesai.

  6. Ekspor dan pengujian lokal

  - Unduh jawaban.py setelah seluruh test browser lulus.
  - Jalankan `python jawaban.py --export folder_baru` untuk membuat folder proyek yang belum ada. Ekspor tidak menimpa folder yang sudah ada.
  - Dari folder hasil ekspor, jalankan `Get-Content contoh_input.txt | python -m a6_inventaris` pada PowerShell.
  - Jalankan `python -m unittest discover -s tests -v`; tiga unit test yang disediakan harus lulus.
  - Ikuti arahan pengajar untuk mengumpulkan bundle Python dan/atau folder proyek. Save File tidak otomatis mengirim jawaban.

  7. Contoh input

  Setiap butir adalah satu baris input.
  - `4`
  - `B 10`
  - `A 5`
  - `B -3`
  - `C 0`
  - `0`

  8. Contoh output harness

  Setiap butir adalah satu baris output.
  - `Import Tenang: True`
  - `API: a6_inventaris.services`
  - `Model API: True`
  - `Layanan Tenang: True`
  - `Layanan: ['A=5', 'B=7', 'C=0']`
  - `Ulang: ['A=5', 'B=7', 'C=0']`
  - `Data Tetap: True`
  - `List Baru: True`
  - `CLI: ['A=5', 'B=7', 'C=0']`
  - `Package: ['A=5', 'B=7', 'C=0']`

  Assignment 6, Chapter 8. Memerlukan Python 3.10 atau lebih baru.

  PACKAGE = 'a6_inventaris'
  API = 'rekap_stok'
  MODEL = 'MutasiStok'

  from contextlib import redirect_stdout
  from io import StringIO
  from pathlib import Path
  from tempfile import TemporaryDirectory
  import copy
  import importlib
  import runpy
  import sys


  def tulis_proyek(root):
      for name, source in FILES.items():
          relatif = Path(name)
          if relatif.is_absolute() or '..' in relatif.parts:
              raise ValueError('Nama file harus relatif di dalam proyek')
          path = root / relatif
          path.parent.mkdir(parents=True, exist_ok=True)
          path.write_text(source, encoding='utf-8')


  def bersihkan_package():
      for name in list(sys.modules):
          if name == PACKAGE or name.startswith(PACKAGE + '.'):
              sys.modules.pop(name, None)


  def jalankan_module(nama, teks):
      sebelumnya = sys.stdin
      output = StringIO()
      try:
          sys.stdin = StringIO(teks)
          with redirect_stdout(output):
              runpy.run_module(nama, run_name='__main__')
      finally:
          sys.stdin = sebelumnya
      return output.getvalue().splitlines()


  def periksa(teks):
      bersihkan_package()
      with TemporaryDirectory() as folder:
          root = Path(folder)
          tulis_proyek(root)
          sys.path.insert(0, folder)
          importlib.invalidate_caches()
          try:
              output_import = StringIO()
              with redirect_stdout(output_import):
                  package = importlib.import_module(PACKAGE)
                  importlib.import_module(PACKAGE + '.cli')
                  models = importlib.import_module(PACKAGE + '.models')
                  adapter = importlib.import_module(PACKAGE + '.input_adapter')
                  formatter = importlib.import_module(PACKAGE + '.formatters')
              api = getattr(package, API)
              model = getattr(models, MODEL)
              data, opsi = adapter.baca(teks)
              sebelum = copy.deepcopy((data, opsi))
              output_layanan = StringIO()
              with redirect_stdout(output_layanan):
                  pertama = api(data, opsi)
                  kedua = api(data, opsi)
                  tampilan1 = formatter.format_hasil(pertama, opsi)
                  tampilan2 = formatter.format_hasil(kedua, opsi)
              print('Import Tenang:', output_import.getvalue() == '')
              print('API:', api.__module__)
              print('Model API:', getattr(package, MODEL) is model and model.__module__ == PACKAGE + '.models')
              print('Layanan Tenang:', output_layanan.getvalue() == '')
              print('Layanan:', tampilan1)
              print('Ulang:', tampilan2)
              print('Data Tetap:', (data, opsi) == sebelum)
              print('List Baru:', isinstance(pertama, list) and isinstance(kedua, list) and pertama is not kedua)
              sys.modules.pop(PACKAGE + '.cli', None)
              print('CLI:', jalankan_module(PACKAGE + '.cli', teks))
              print('Package:', jalankan_module(PACKAGE, teks))
          finally:
              sys.path.remove(folder)
              bersihkan_package()
              importlib.invalidate_caches()


  # Harness tetap: mendukung ekspor folder proyek atau pemeriksaan di browser.
  if len(sys.argv) > 1 and sys.argv[1] == '--export':
      if len(sys.argv) != 3:
          raise ValueError('Gunakan python jawaban.py --export folder_baru')
      tujuan = Path(sys.argv[2])
      tujuan.mkdir(parents=True, exist_ok=False)
      tulis_proyek(tujuan)
      print('Proyek diekspor ke:', tujuan.resolve())
  else:
      periksa(sys.stdin.read())
