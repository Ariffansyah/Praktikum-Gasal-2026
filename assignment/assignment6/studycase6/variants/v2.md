  Tugas: Tarif Parkir Modular

  Susun package a6_parkirkampus agar aturan perhitungan, service, formatter, dan CLI dapat digunakan secara terpisah. Isi setiap file berada dalam dictionary FILES pada starter. Ubah hanya komentar TODO di dalam string file yang bersangkutan; jangan mengganti nama file, harness, data class, input adapter, contoh, atau unit test yang diberikan.

  1. Struktur dan tanggung jawab

  - `a6_parkirkampus/models.py`: data dan model.
  - `a6_parkirkampus/input_adapter.py`: parser input yang sudah diberikan.
  - `a6_parkirkampus/rules.py`: helper atau subpackage yang diberikan.
  - `a6_parkirkampus/services.py`: service aplikasi.
  - `a6_parkirkampus/formatters.py`: formatter tampilan.
  - `a6_parkirkampus/cli.py`: stdin/stdout dan main guard.
  - `a6_parkirkampus/__init__.py`: public API/regular package.
  - `a6_parkirkampus/__main__.py`: entry point package.

  2. Kontrak khusus varian

  - Module models.py sudah menyediakan KendaraanParkir(kode, jenis, unit) dan frozen HasilParkir(kode, total).
  - rules.py menyediakan konstanta TARIF = {'motor': 2000, 'mobil': 5000, 'bus': 10000}. Lengkapi hitung(jenis, unit) menggunakan konstanta itu.
  - services.py harus mengimpor HasilParkir dari models dan hitung dari rules melalui relative import. rekap(data, opsi) mengembalikan LIST BARU HasilParkir dalam urutan input; opsi kosong diabaikan. Perhitungan hanya dilakukan oleh rules.hitung().
  - formatters.py: format_hasil(hasil, opsi) mengembalikan list string kode=total. Jangan mencetak dari service, formatter, atau rules.
  - cli.py sudah menyediakan parser dan alur main(). Lengkapi import API package serta formatter, lalu tambahkan main guard.
  - __init__.py mengekspor rekap dan KendaraanParkir sebagai public API. __main__.py mengimpor main dari cli dan memanggilnya hanya saat menjadi kode top-level.
  - Input tidak diubah; dua pemanggilan rekap menghasilkan list berbeda dengan isi setara.

  3. Aturan modularisasi

  - Public API harus mengekspor `rekap` dari `services.py` dan `KendaraanParkir` dari `models.py`. Jangan membuat wrapper baru pada __init__.py atau menyalin definisi function/class ke file lain.
  - Gunakan import dan alias sesuai kontrak; helper dan model tidak mengimpor CLI. `input_adapter.py` dan isi `main()` CLI sudah disediakan.
  - Lengkapi main guard pada `cli.py` dan `__main__.py`. Import normal tidak menjalankan aplikasi, membaca stdin, atau mencetak laporan.
  - Service menerima data/opsi, mengembalikan LIST BARU hasil setiap pemanggilan, dan tidak mengubah data maupun opsi. Formatter mengembalikan list string; hanya CLI yang mencetak.
  - Semua contoh memakai Python standard library. Jangan memasang dependency tambahan, memodifikasi sys.path di file aplikasi, atau menghapus pemisahan module untuk mengejar output.

  4. Format input

  Baris pertama n (0..20). Berikutnya n baris: jenis kode unit. Jenis adalah motor, mobil, bus. Kode unik tanpa spasi dan unit integer 0..1000 (jam). Tidak ada baris opsi tambahan. Semua input valid.

  5. Hasil aplikasi dan pemeriksaan

  Setiap hasil CLI adalah kode=total per baris, sesuai urutan input. Input kosong menghasilkan nol baris CLI. Program pemeriksa browser membungkus baris tersebut dalam list pada label Layanan, Ulang, CLI, dan Package.

  Harness mencetak 10 label. Import Tenang dan Layanan Tenang harus True. API harus `a6_parkirkampus.services`; Model API harus True. Layanan dan Ulang adalah list hasil formatter untuk dua pemanggilan service. Data Tetap memeriksa data beserta opsi; List Baru memastikan hasil service tidak dipakai ulang. CLI dan Package berisi hasil menjalankan module CLI dan entry point package dengan input yang sama. Keduanya harus sama dengan Layanan.

  Gunakan Run Tests karena Run tidak menyediakan input otomatis. Program yang belum lengkap dapat menghasilkan ImportError, AttributeError, atau NameError sampai seluruh TODO terkait selesai.

  6. Ekspor dan pengujian lokal

  - Unduh jawaban.py setelah seluruh test browser lulus.
  - Jalankan `python jawaban.py --export folder_baru` untuk membuat folder proyek yang belum ada. Ekspor tidak menimpa folder yang sudah ada.
  - Dari folder hasil ekspor, jalankan `Get-Content contoh_input.txt | python -m a6_parkirkampus` pada PowerShell.
  - Jalankan `python -m unittest discover -s tests -v`; tiga unit test yang disediakan harus lulus.
  - Ikuti arahan pengajar untuk mengumpulkan bundle Python dan/atau folder proyek. Save File tidak otomatis mengirim jawaban.

  - `bus C 1`

  PACKAGE = 'a6_parkirkampus'
  API = 'rekap'
  MODEL = 'KendaraanParkir'

  from contextlib import redirect_stdout
  from io import StringIO
  from pathlib import Path
  from tempfile import TemporaryDirectory
  import copy
  import importlib
  import runpy
  import sys


  def tulis_proyek(root):
      for name, source in FILES.items():
          relatif = Path(name)
          if relatif.is_absolute() or '..' in relatif.parts:
              raise ValueError('Nama file harus relatif di dalam proyek')
          path = root / relatif
          path.parent.mkdir(parents=True, exist_ok=True)
          path.write_text(source, encoding='utf-8')


  def bersihkan_package():
      for name in list(sys.modules):
          if name == PACKAGE or name.startswith(PACKAGE + '.'):
              sys.modules.pop(name, None)


  def jalankan_module(nama, teks):
      sebelumnya = sys.stdin
      output = StringIO()
      try:
          sys.stdin = StringIO(teks)
          with redirect_stdout(output):
              runpy.run_module(nama, run_name='__main__')
      finally:
          sys.stdin = sebelumnya
      return output.getvalue().splitlines()


  def periksa(teks):
      bersihkan_package()
      with TemporaryDirectory() as folder:
          root = Path(folder)
          tulis_proyek(root)
          sys.path.insert(0, folder)
          importlib.invalidate_caches()
          try:
              output_import = StringIO()
              with redirect_stdout(output_import):
                  package = importlib.import_module(PACKAGE)
                  importlib.import_module(PACKAGE + '.cli')
                  models = importlib.import_module(PACKAGE + '.models')
                  adapter = importlib.import_module(PACKAGE + '.input_adapter')
                  formatter = importlib.import_module(PACKAGE + '.formatters')
              api = getattr(package, API)
              model = getattr(models, MODEL)
              data, opsi = adapter.baca(teks)
              sebelum = copy.deepcopy((data, opsi))
              output_layanan = StringIO()
              with redirect_stdout(output_layanan):
                  pertama = api(data, opsi)
                  kedua = api(data, opsi)
                  tampilan1 = formatter.format_hasil(pertama, opsi)
                  tampilan2 = formatter.format_hasil(kedua, opsi)
              print('Import Tenang:', output_import.getvalue() == '')
              print('API:', api.__module__)
              print('Model API:', getattr(package, MODEL) is model and model.__module__ == PACKAGE + '.models')
              print('Layanan Tenang:', output_layanan.getvalue() == '')
              print('Layanan:', tampilan1)
              print('Ulang:', tampilan2)
              print('Data Tetap:', (data, opsi) == sebelum)
              print('List Baru:', isinstance(pertama, list) and isinstance(kedua, list) and pertama is not kedua)
              sys.modules.pop(PACKAGE + '.cli', None)
              print('CLI:', jalankan_module(PACKAGE + '.cli', teks))
              print('Package:', jalankan_module(PACKAGE, teks))
          finally:
              sys.path.remove(folder)
              bersihkan_package()
              importlib.invalidate_caches()


  # Harness tetap: mendukung ekspor folder proyek atau pemeriksaan di browser.

      tujuan.mkdir(parents=True, exist_ok=False)
      tulis_proyek(tujuan)
      print('Proyek diekspor ke:', tujuan.resolve())
  else:
      periksa(sys.stdin.read())
