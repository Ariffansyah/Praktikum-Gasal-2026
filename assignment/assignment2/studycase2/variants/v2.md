  Tugas
  
  Lengkapi class `JadwalKelas` untuk mengelola durasi satu jadwal kuliah. Program membuat object melalui class method, mengubah durasi satu kali, lalu menentukan kategori durasinya.
  
  1. Tujuan tugas
  
  Terapkan class method sebagai factory, static method untuk validasi, custom decorator, chaining decorator, dan penerusan `*args` serta `**kwargs`.
  
  2. Spesifikasi class
  
  - `total_jadwal = 0`, `total_perubahan = 0`, dan `durasi_maksimal = 240` adalah class attribute.
  - Constructor menerima `(mata_kuliah, hari, mulai, durasi, ruang)`. Simpan empat data pertama yang sesuai sebagai public attribute, kecuali `durasi` yang disimpan melalui property private `__durasi`.
  - Durasi harus berada pada rentang 30 sampai 240 menit. Setter menghasilkan `ValueError("Durasi harus berada pada rentang 30 sampai 240.")` jika tidak valid.
  - Setiap object baru menambah `JadwalKelas.total_jadwal` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima format `mata_kuliah hari mulai durasi ruang`, mengubah underscore pada nama mata kuliah menjadi spasi, mengubah durasi menjadi integer, dan mengembalikan `cls(...)`.
  - `@staticmethod ruang_valid(kode)` mengembalikan `True` jika kode terdiri dari huruf `C` diikuti tepat tiga digit. Selain itu `False`.
  
  4. Decorator dan method
  
  Buat decorator `hitung_perubahan` dan `hasil_boolean`. Masing-masing harus memiliki `wrapper(*args, **kwargs)` dan meneruskan semua argument ke function yang dibungkus. `hitung_perubahan` menambah `JadwalKelas.total_perubahan` untuk setiap percobaan `ubah_durasi`, termasuk yang gagal. `hasil_boolean` mengembalikan hasil function dalam bentuk boolean.
  
  Pasang kedua decorator pada `ubah_durasi`. Method ini menerima `tambahan`, berhasil jika tambahan lebih dari nol dan durasi baru tidak melebihi `durasi_maksimal`. Jika berhasil, gunakan property untuk menyimpan durasi baru. Jika gagal, state tidak berubah.
  
  `kategori()` mengembalikan `"Singkat"` untuk durasi sampai 60, `"Normal"` untuk durasi 61 sampai 120, dan `"Panjang"` untuk durasi lebih dari 120.
  
  5. Program utama dan output
  
  Input memiliki format `mata_kuliah hari mulai durasi ruang tambahan`. Program utama menggunakan class method dan mengirim `tambahan` sebagai keyword argument.
  
  Output harus tepat delapan baris: `Mata Kuliah`, `Hari`, `Mulai`, `Durasi`, `Kategori`, `Ruang Valid`, `Perubahan Berhasil`, `Total Jadwal`, dan `Total Perubahan`.
  
  6. Aturan
  
  - Lengkapi TODO tanpa mengubah program utama.
  - Jangan menggunakan inheritance atau library tambahan.
  - Jangan mengubah label output atau signature method.
  - Perubahan yang gagal tidak mengubah durasi, tetapi tetap dihitung sebagai percobaan.
  
  Checklist sebelum Run Tests
  
  - Factory method menggunakan `cls(...)`.
  - Static method tidak memakai `self` atau `cls`.
  - Chaining tetap dipasang pada `ubah_durasi`.
  - Wrapper dapat menerima positional dan keyword arguments.
