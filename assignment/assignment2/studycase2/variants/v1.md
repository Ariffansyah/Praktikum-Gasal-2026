prompt: |
  Tugas
  
  Lengkapi class `Produk` untuk mengelola stok sebuah produk. Program utama membuat object melalui class method `dari_teks`, menjalankan satu perubahan stok, lalu menampilkan hasilnya.
  
  1. Tujuan tugas
  
  Gunakan class attribute, class method, static method, custom decorator, chaining decorator, serta `*args` dan `**kwargs` pada wrapper decorator.
  
  2. Spesifikasi class `Produk`
  
  - `total_produk = 0` dan `total_operasi = 0` adalah class attribute.
  - `stok_maksimal = 10` adalah class attribute.
  - Constructor menerima `(nama, harga, stok, kode)`. Simpan `nama`, `harga`, dan `kode` sebagai public attribute.
  - Simpan stok pada private attribute `__stok` melalui property `stok`. Stok tidak boleh negatif.
  - Setiap object baru menambah `Produk.total_produk` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima teks dengan format `nama harga stok kode`. Nilai nama menggunakan underscore untuk spasi. Ubah harga dan stok menjadi integer, lalu kembalikan object baru menggunakan `cls(...)`.
  - `@staticmethod kode_valid(kode)` mengembalikan `True` jika kode terdiri dari huruf `P` diikuti tepat tiga digit. Selain itu `False`.
  
  4. Decorator dan method
  
  Buat dua custom decorator berikut di luar class.
  
  - `hitung_operasi(func)` harus memiliki `wrapper(*args, **kwargs)`. Jalankan function asli, lalu tambah `total_operasi` satu kali untuk setiap pemanggilan `ubah_stok`, baik berhasil maupun gagal.
  - `hasil_boolean(func)` juga harus memiliki `wrapper(*args, **kwargs)` dan mengembalikan hasil function asli dalam bentuk boolean.
  
  Pasang kedua decorator pada `ubah_stok` dengan chaining. `ubah_stok(jumlah)` berhasil jika `jumlah` lebih dari nol dan stok baru tidak melebihi `stok_maksimal`. Jika berhasil, ubah stok melalui property dan kembalikan `True`. Jika gagal, kembalikan `False` tanpa mengubah stok.
  
  `status()` mengembalikan `"Tersedia"` jika stok lebih dari nol dan `"Habis"` jika stok sama dengan nol.
  
  5. Program utama dan output
  
  Jangan mengubah program utama. Input memiliki format `nama harga stok kode jumlah`. Program utama sengaja memanggil `ubah_stok` dengan keyword argument agar wrapper mendukung `**kwargs`.
  
  Output harus tepat delapan baris: `Nama`, `Harga`, `Stok`, `Status`, `Kode Valid`, `Perubahan Berhasil`, `Total Produk`, dan `Total Operasi`.
  
  6. Aturan
  
  - Lengkapi bagian `TODO` saja.
  - Jangan mengubah nama class, method, parameter, decorator, label, atau urutan program utama.
  - Jangan menggunakan inheritance atau library tambahan.
  - Semua counter harus diubah pada tingkat class.
  
  Checklist sebelum Run Tests
  
  - Object dibuat dengan `Produk.dari_teks(...)`.
  - `kode_valid` tidak menggunakan `self` atau `cls`.
  - Kedua decorator menggunakan `*args` dan `**kwargs` serta meneruskan argumen ke function asli.
  - Percobaan gagal tidak mengubah stok, tetapi tetap dihitung sebagai operasi.
