prompt: |
  Tugas
  
  Lengkapi class `Tabungan` untuk mengelola satu rekening sederhana. Program membuat object dari teks, mencoba satu setoran, lalu menampilkan saldo dan kategori tabungan.
  
  1. Tujuan tugas
  
  Praktikkan class method, static method, custom decorator, chaining decorator, dan penggunaan `*args` serta `**kwargs` pada wrapper.
  
  2. Spesifikasi class
  
  - `total_rekening = 0` dan `total_setoran = 0` adalah class attribute.
  - `saldo_maksimal = 1000000` adalah class attribute.
  - Constructor menerima `(nama, nomor, saldo)`. Simpan `nama` dan `nomor` sebagai public attribute. Simpan saldo pada private attribute `__saldo` melalui property.
  - Saldo harus berada pada rentang 0 sampai `saldo_maksimal`.
  - Setiap object baru menambah `Tabungan.total_rekening` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima format `nama nomor saldo`, mengubah nama yang menggunakan underscore menjadi spasi, mengubah saldo menjadi integer, dan mengembalikan `cls(...)`.
  - `@staticmethod nomor_valid(nomor)` mengembalikan `True` jika nomor terdiri dari huruf `A` diikuti tepat empat digit. Selain itu `False`.
  
  4. Decorator dan method
  
  Buat decorator `catat_setoran` dan `hasil_boolean`. Keduanya harus menggunakan `wrapper(*args, **kwargs)` serta meneruskan argument ke function asli. `catat_setoran` menaikkan `Tabungan.total_setoran` pada setiap percobaan `setor`, sedangkan `hasil_boolean` mengembalikan hasil dalam bentuk boolean.
  
  Pasang kedua decorator pada `setor`. Setoran berhasil jika jumlah lebih dari nol dan saldo baru tidak melebihi `saldo_maksimal`. Jika berhasil, ubah saldo melalui property. Jika gagal, saldo tetap.
  
  `kategori()` mengembalikan `"Kosong"` untuk saldo 0, `"Standar"` untuk saldo 1 sampai 500000, dan `"Tinggi"` untuk saldo lebih dari 500000.
  
  5. Program utama dan output
  
  Input memiliki format `nama nomor saldo jumlah_setor`. Program utama memanggil factory method dan mengirim jumlah setoran sebagai keyword argument.
  
  Output harus tepat delapan baris: `Nama`, `Nomor`, `Saldo`, `Kategori`, `Nomor Valid`, `Setor Berhasil`, `Total Rekening`, dan `Total Setoran`.
  
  6. Aturan
  
  - Lengkapi TODO saja dan pertahankan program utama.
  - Jangan memakai inheritance atau library tambahan.
  - Setoran invalid tidak mengubah saldo, tetapi tetap dihitung sebagai percobaan.
  - Jangan mengubah nama decorator, method, parameter, atau label output.
  
  Checklist sebelum Run Tests
  
  - `dari_teks` menggunakan `cls(...)`.
  - `nomor_valid` dapat dipanggil tanpa membuat object.
  - Dua decorator benar-benar tersusun pada `setor`.
  - Wrapper meneruskan keyword argument ke function asli.
