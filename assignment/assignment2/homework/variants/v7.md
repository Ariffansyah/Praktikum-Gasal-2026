  Tugas
  
  Lengkapi class `Playlist` untuk mengelola jumlah lagu dan total durasi playlist. Object dibuat dari teks, menerima satu penambahan lagu, lalu dapat diarsipkan.
  
  1. Tujuan tugas
  
  Terapkan class method, static method, custom decorator, chaining decorator, serta `*args` dan `**kwargs`.
  
  2. Spesifikasi class
  
  - `total_playlist = 0`, `total_lagu = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `batas_lagu = 50` adalah class attribute.
  - Constructor menerima `(nama, kode, lagu_awal)`. Simpan nama dan kode sebagai public attribute. Simpan jumlah lagu pada property `jumlah_lagu` dengan private attribute `__jumlah_lagu` dan durasi pada private `__durasi`.
  - Jumlah lagu berada pada rentang 0 sampai batas. Object baru menambah `total_playlist` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima `nama kode lagu_awal`, mengubah nama underscore menjadi spasi, mengubah lagu menjadi integer, dan memakai `cls(...)`.
  - `@staticmethod kode_valid(kode)` mengembalikan `True` jika kode diawali `P` dan diikuti tepat tiga digit.
  
  4. Decorator dan method
  
  Buat `catat_percobaan` dan `playlist_aktif`; keduanya memiliki wrapper `(*args, **kwargs)` dan meneruskan argument. Pencatat menambah `total_percobaan` setiap `tambah_lagu` dipanggil. Decorator aktif menolak jika playlist diarsipkan.
  
  `tambah_lagu(jumlah, durasi_per_lagu)` berhasil jika jumlah dan durasi positif, serta jumlah lagu baru tidak melebihi batas. Jika berhasil, ubah property jumlah lagu, tambah durasi private, dan tambah `Playlist.total_lagu` sebanyak jumlah. Jika gagal, state tidak berubah. `arsipkan()` mengubah status menjadi `"Arsip"`; `status()` mengembalikan `"Arsip"`, `"Penuh"`, atau `"Aktif"`.
  
  5. Program utama dan output
  
  Input: `nama kode lagu_awal jumlah durasi kode_uji arsip`. Pemanggilan `tambah_lagu` memakai keyword arguments. Ikuti output starter code.
  
  6. Aturan
  
  Lengkapi TODO saja. Jangan mengubah program utama, label, signature, decorator, dan urutan operasi. Jangan memakai inheritance/library. Counter lagu dan durasi hanya berubah saat operasi berhasil.
  
  Checklist sebelum Run Tests
  
  - Factory memakai `cls`.
  - Validator tidak memakai `self`.
  - Semua wrapper meneruskan positional dan keyword arguments.
  - Penambahan invalid tidak mengubah jumlah lagu maupun durasi.
