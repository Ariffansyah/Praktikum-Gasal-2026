  Tugas
  
  Lengkapi class `Pengiriman` untuk mengelola berat total paket yang dikirim dari satu agen. Object dibuat melalui factory method, menerima satu paket, lalu dapat ditutup.
  
  1. Tujuan tugas
  
  Terapkan class method, static method, custom decorator, chaining decorator, serta `*args` dan `**kwargs`.
  
  2. Spesifikasi class
  
  - `total_agen = 0`, `total_berat = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `kapasitas_kg = 100` adalah batas berat satu agen.
  - Constructor menerima `(nama_agen, wilayah, berat_awal)`. Simpan nama dan wilayah sebagai public attribute. Simpan berat melalui property `berat` dengan private attribute `__berat`.
  - Berat berada pada rentang 0 sampai `kapasitas_kg`. Object baru menambah `total_agen` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima `nama_agen wilayah berat_awal`, mengubah underscore pada nama menjadi spasi, mengubah berat menjadi float, dan menggunakan `cls(...)`.
  - `@staticmethod wilayah_valid(kode)` mengembalikan `True` jika kode terdiri dari `W` dan dua digit.
  
  4. Decorator dan method
  
  Buat decorator `catat_percobaan` dan `agen_aktif`. Wrapper wajib menerima dan meneruskan `*args`, `**kwargs`. Decorator pencatat menaikkan `Pengiriman.total_percobaan` setiap kali `kirim` dipanggil. Decorator kedua menolak pengiriman setelah agen ditutup.
  
  Hias `kirim(berat, tarif_per_kg)` dengan kedua decorator. Berhasil jika berat lebih dari nol, tarif tidak negatif, dan kapasitas masih cukup. Jika berhasil, ubah property `berat`, tambahkan biaya private `__pendapatan`, dan tambah `Pengiriman.total_berat` sebesar berat paket. Jika gagal, state transaksi tidak berubah.
  
  `tutup()` mengubah status menjadi `"Ditutup"`; `status()` mengembalikan `"Penuh"`, `"Ditutup"`, atau `"Tersedia"`.
  
  5. Program utama dan output
  
  Input: `nama_agen wilayah berat_awal berat tarif wilayah_uji tutup`. Program utama mengirim dua parameter kirim dengan keyword.
  
  Output mengikuti starter code. Jangan menambah print.
  
  6. Aturan
  
  Lengkapi TODO saja. Jangan mengubah signature, decorator, program utama, label output, atau urutan operasi. Jangan memakai inheritance/library. Gunakan float tanpa membulatkan berat.
  
  Checklist sebelum Run Tests
  
  - Factory memakai `cls` dan validator dapat dipanggil melalui class.
  - Decorator meneruskan positional/keyword arguments.
  - Kapasitas dicek sebelum state diubah.
  - Counter berat hanya bertambah ketika pengiriman berhasil.
