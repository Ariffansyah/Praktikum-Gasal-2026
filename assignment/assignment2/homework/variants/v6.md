  Tugas
  
  Lengkapi class `Hotel` untuk mengelola reservasi kamar. Object dibuat dari teks, menerima satu reservasi, lalu dapat ditutup.
  
  1. Tujuan tugas
  
  Gunakan class method, static method, dua custom decorator, chaining, serta wrapper `*args` dan `**kwargs`.
  
  2. Spesifikasi class
  
  - `total_hotel = 0`, `total_kamar_terisi = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `kapasitas_kamar = 50` adalah batas kamar.
  - Constructor menerima `(nama, kota, kamar_awal)`. Simpan nama dan kota sebagai public attribute. Simpan kamar terisi melalui property `kamar_terisi` dengan private attribute `__kamar_terisi`.
  - Kamar terisi berada pada rentang 0 sampai kapasitas. Object baru menambah `total_hotel` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima `nama kota kamar_awal`, mengubah underscore pada nama menjadi spasi, mengubah kamar menjadi integer, lalu memakai `cls(...)`.
  - `@staticmethod kota_valid(kode)` mengembalikan `True` jika kode diawali `K` dan diikuti tepat dua digit.
  
  4. Decorator dan method
  
  Buat `catat_percobaan` dan `hotel_buka`. Keduanya harus memakai `wrapper(*args, **kwargs)` dan meneruskan argument. Decorator pertama menambah counter setiap `reservasi` dipanggil; decorator kedua menolak saat hotel berstatus `"Tutup"`.
  
  `reservasi(jumlah, harga_per_malam)` berhasil jika jumlah positif, harga tidak negatif, dan kamar cukup. Jika berhasil, ubah property, tambah private `__pendapatan`, dan tambah counter class sebanyak jumlah kamar. Jika gagal, state transaksi tidak berubah. `tutup()` mengubah status menjadi `"Tutup"`; `status()` mengembalikan `"Tutup"`, `"Penuh"`, atau `"Buka"`.
  
  5. Program utama dan output
  
  Input: `nama kota kamar_awal jumlah harga kode_uji tutup`. Program utama memanggil `reservasi` dengan keyword arguments.
  
  Output mengikuti starter code.
  
  6. Aturan
  
  Lengkapi TODO saja. Jangan mengubah starter code utama, signature, decorator, label, dan urutan operasi. Jangan memakai inheritance/library. Counter pendapatan hanya bertambah ketika reservasi berhasil.
  
  Checklist sebelum Run Tests
  
  - `dari_teks` memakai `cls`.
  - `kota_valid` berdiri sendiri.
  - Decorator menerima dan meneruskan `*args`, `**kwargs`.
  - Reservasi yang melampaui kapasitas tidak mengubah kamar atau pendapatan.
