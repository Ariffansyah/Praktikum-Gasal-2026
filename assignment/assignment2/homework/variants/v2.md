  Tugas
  
  Lengkapi class `PendaftaranKursus` untuk mengelola jumlah peserta dan pendapatan satu kelas kursus. Object dibuat dari teks, menerima satu pendaftaran, lalu dapat ditutup.
  
  1. Tujuan tugas
  
  Terapkan class method, static method, custom decorator, chaining decorator, serta forwarding `*args` dan `**kwargs`.
  
  2. Spesifikasi class
  
  - `total_kelas = 0`, `total_peserta = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `kapasitas = 30` adalah class attribute.
  - Constructor menerima `(nama_kursus, pengajar, peserta_awal)`. Simpan nama kursus dan pengajar sebagai public attribute. Simpan peserta pada property `peserta` dengan private attribute `__peserta`.
  - Peserta harus berada pada rentang 0 sampai `kapasitas`. Object baru menambah `total_kelas` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima `nama_kursus pengajar peserta_awal`, mengubah underscore pada nama kursus menjadi spasi, mengubah peserta awal menjadi integer, lalu menggunakan `cls(...)`.
  - `@staticmethod kode_pengajar_valid(kode)` mengembalikan `True` jika kode diawali `D` dan diikuti tepat tiga digit.
  
  4. Decorator dan method
  
  Buat `catat_percobaan` dan `hanya_terbuka`. Wrapper keduanya harus berbentuk `wrapper(*args, **kwargs)`. Decorator pertama menambah `PendaftaranKursus.total_percobaan` pada setiap pemanggilan `daftar`, sedangkan decorator kedua menolak operasi jika kelas sudah ditutup atau sudah penuh.
  
  Hias `daftar` dengan kedua decorator sesuai starter code. `daftar(jumlah, biaya)` berhasil jika jumlah lebih dari nol, biaya per peserta tidak negatif, dan kuota masih cukup. Jika berhasil, ubah property `peserta`, tambah pendapatan private `__pendapatan`, dan tambah `PendaftaranKursus.total_peserta` sebanyak jumlah. Jika gagal, state tidak berubah.
  
  `tutup()` mengubah status menjadi `"Ditutup"`. `status()` mengembalikan `"Ditutup"`, `"Penuh"`, atau `"Terbuka"` sesuai state.
  
  5. Program utama dan output
  
  Input: `nama_kursus pengajar peserta_awal jumlah biaya kode_pengajar tutup`. Nama kursus boleh memakai underscore. Pemanggilan `daftar` menggunakan keyword arguments.
  
  Output harus tepat sembilan baris sesuai starter code.
  
  6. Aturan dan checklist
  
  - Lengkapi TODO saja; jangan mengubah program utama dan label output.
  - Factory harus menggunakan `cls`, validator tidak menggunakan `self` atau `cls`.
  - Kedua decorator harus meneruskan semua positional dan keyword arguments.
  - Pendaftaran yang ditolak tidak mengubah peserta atau pendapatan.
  - Jangan menggunakan inheritance atau library tambahan.
