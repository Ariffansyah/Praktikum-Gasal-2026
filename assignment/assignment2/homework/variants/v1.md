prompt: |
  Tugas
  
  Lengkapi class `Pesanan` untuk mengelola jumlah item dan total harga sebuah pesanan restoran. Program utama membuat object melalui factory method, mencoba menambah item, lalu boleh menutup pesanan.
  
  1. Tujuan tugas
  
  Terapkan class method, static method, custom decorator, chaining decorator, dan wrapper yang menerima `*args` serta `**kwargs`.
  
  2. Spesifikasi class `Pesanan`
  
  - `total_pesanan = 0`, `total_item_terjual = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `batas_item = 20` adalah class attribute.
  - Constructor menerima `(nama_pelanggan, meja, jumlah_awal)`. Simpan nama dan meja sebagai public attribute. Simpan jumlah item melalui property `jumlah_item` yang menggunakan private attribute `__jumlah_item`.
  - Jumlah item harus berada pada rentang 0 sampai `batas_item`.
  - Object baru menambah `total_pesanan` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima format `nama_pelanggan meja jumlah_awal`. Ubah underscore pada nama menjadi spasi, ubah jumlah awal menjadi integer, lalu buat object menggunakan `cls(...)`.
  - `@staticmethod meja_valid(kode)` mengembalikan `True` jika kode diawali `M` dan diikuti tepat dua digit. Selain itu `False`.
  
  4. Decorator dan method
  
  Buat decorator `catat_percobaan` dan `hanya_aktif`. Keduanya wajib memiliki `wrapper(*args, **kwargs)` dan meneruskan argument ke function asli. `catat_percobaan` menambah `Pesanan.total_percobaan` satu kali untuk setiap pemanggilan `tambah_item`, termasuk saat operasi ditolak. `hanya_aktif` mengembalikan `False` jika pesanan sudah ditutup.
  
  Pasang decorator pada `tambah_item` sesuai starter code. Method `tambah_item(jumlah, harga_satuan)` berhasil jika jumlah lebih dari nol, harga tidak negatif, dan jumlah item baru tidak melebihi batas. Jika berhasil, perbarui `jumlah_item` melalui property, tambahkan total harga, dan tambahkan `Pesanan.total_item_terjual` sebanyak jumlah item. Jika gagal, state tidak berubah.
  
  `tutup()` mengubah status menjadi `"Ditutup"`. `status()` mengembalikan `"Ditutup"` atau `"Aktif"`.
  
  5. Program utama dan output
  
  Input: `nama_pelanggan meja jumlah_awal jumlah harga_satuan tutup`. Program utama menggunakan keyword argument saat memanggil `tambah_item`.
  
  Output harus tepat sembilan baris: `Nama`, `Meja`, `Jumlah Item`, `Total Harga`, `Status`, `Meja Valid`, `Tambah Berhasil`, `Total Pesanan`, dan `Total Percobaan`.
  
  6. Aturan
  
  - Lengkapi TODO saja dan jangan mengubah program utama, signature, decorator, label, atau urutan operasi.
  - Jangan menggunakan inheritance atau library tambahan.
  - Operasi gagal tidak mengubah jumlah item maupun total harga.
  - Counter class tidak boleh dibuat sebagai instance attribute.
  
  Checklist sebelum Run Tests
  
  - Factory memakai `cls(...)`.
  - Validator meja tidak membutuhkan `self` atau `cls`.
  - Kedua decorator tetap terpasang dan meneruskan `*args`, `**kwargs`.
  - Pemanggilan keyword `jumlah` dan `harga_satuan` tetap bekerja.
