  Tugas
  
  Lengkapi class `Kampanye` untuk mengelola dana sebuah kampanye donasi. Object dibuat dari teks, menerima satu donasi, lalu dapat diselesaikan.
  
  1. Tujuan tugas
  
  Terapkan class method, static method, custom decorator, chaining decorator, serta `*args` dan `**kwargs`.
  
  2. Spesifikasi class
  
  - `total_kampanye = 0`, `total_donasi = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `target_dana = 10000000` adalah class attribute.
  - Constructor menerima `(nama, kode, dana_awal)`. Simpan nama dan kode sebagai public attribute. Simpan dana melalui property `dana` dengan private attribute `__dana`.
  - Dana harus berada pada rentang 0 sampai target dana. Object baru menambah `total_kampanye` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima `nama kode dana_awal`, mengubah underscore pada nama menjadi spasi, mengubah dana menjadi integer, lalu menggunakan `cls(...)`.
  - `@staticmethod kode_valid(kode)` mengembalikan `True` jika kode terdiri dari `D` diikuti tepat tiga digit.
  
  4. Decorator dan method
  
  Buat decorator `catat_percobaan` dan `kampanye_aktif`. Keduanya harus memiliki `wrapper(*args, **kwargs)` dan meneruskan argument ke function asli. Decorator pertama menaikkan `Kampanye.total_percobaan` pada setiap pemanggilan `donasi`; decorator kedua menolak donasi jika kampanye sudah selesai.
  
  `donasi(jumlah)` berhasil jika jumlah lebih dari nol dan dana baru tidak melebihi target. Jika berhasil, ubah property dana, tambah `Kampanye.total_donasi` sebesar jumlah, lalu kembalikan `True`. Jika gagal, dana dan counter donasi tidak berubah.
  
  `selesaikan()` mengubah status menjadi `"Selesai"`. `status()` mengembalikan `"Selesai"`, `"Tercapai"`, atau `"Berjalan"`.
  
  5. Program utama dan output
  
  Input: `nama kode dana_awal jumlah_donasi kode_uji selesai`. Program utama memanggil `donasi` dengan keyword argument.
  
  Output mengikuti starter code. Jangan menambah print.
  
  6. Aturan
  
  Lengkapi TODO saja. Jangan mengubah program utama, signature, label, decorator, atau urutan operasi. Jangan memakai inheritance/library. Donasi invalid tidak mengubah dana dan total donasi.
  
  Checklist sebelum Run Tests
  
  - Factory memakai `cls(...)`.
  - Static method tidak bergantung pada object.
  - Chaining decorator tetap utuh dan wrapper meneruskan `*args`, `**kwargs`.
  - Status ditentukan dari state terakhir.
