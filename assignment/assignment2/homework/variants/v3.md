  Tugas
  
  Lengkapi class `SewaKendaraan`. Program membuat object dari teks, menerima satu permintaan sewa, lalu dapat menutup layanan.
  
  1. Tujuan tugas
  
  Praktikkan class method, static method, custom decorator, chaining decorator, serta penerusan `*args` dan `**kwargs`.
  
  2. Spesifikasi class
  
  - `total_layanan = 0`, `total_unit_disewa = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `kapasitas_unit = 12` adalah jumlah maksimal unit yang dapat disewa pada satu object.
  - Constructor menerima `(jenis, kode, unit_awal)`. Simpan jenis dan kode sebagai public attribute. Simpan unit melalui property `unit_disewa` dengan private attribute `__unit_disewa`.
  - Unit harus berada pada rentang 0 sampai `kapasitas_unit`. Object baru menambah `total_layanan` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima `jenis kode unit_awal`, mengubah unit awal menjadi integer, dan membuat object dengan `cls(...)`.
  - `@staticmethod kode_valid(kode)` mengembalikan `True` jika kode terdiri dari `R` diikuti tepat tiga digit.
  
  4. Decorator dan method
  
  Buat decorator `catat_percobaan` dan `layanan_aktif`. Keduanya harus menggunakan `wrapper(*args, **kwargs)`. Decorator pencatat menaikkan `SewaKendaraan.total_percobaan` setiap kali `sewa` dipanggil. Decorator layanan menolak operasi jika status sudah `"Ditutup"`.
  
  Hias method `sewa(jumlah, tarif_harian)` dengan kedua decorator. Sewa berhasil jika jumlah lebih dari nol, tarif harian tidak negatif, dan unit baru tidak melebihi kapasitas. Jika berhasil, ubah property unit, tambahkan biaya private `__pendapatan`, dan tambah `total_unit_disewa` sebesar jumlah. Jika gagal, semua state transaksi tetap.
  
  `tutup()` menutup layanan. `status()` mengembalikan `"Ditutup"`, `"Penuh"`, atau `"Tersedia"`.
  
  5. Program utama dan output
  
  Input: `jenis kode unit_awal jumlah tarif kode_uji tutup`. Program utama mengirim `jumlah` dan `tarif_harian` sebagai keyword arguments.
  
  Output mengikuti starter code dan tidak boleh ditambah.
  
  6. Aturan
  
  Lengkapi TODO saja. Jangan mengubah signature, urutan decorator, program utama, output, atau nama attribute. Jangan memakai inheritance/library. Operasi invalid tidak mengubah state selain counter percobaan.
  
  Checklist sebelum Run Tests
  
  - Factory dan static method digunakan sesuai perannya.
  - Wrapper meneruskan keyword arguments ke function asli.
  - Batas unit dicek sebelum property diubah.
  - Pendapatan hanya berubah saat sewa berhasil.
