  Tugas
  
  Lengkapi class `DompetDigital`. Program membuat dompet dari teks, mencoba mengisi saldo satu kali, lalu dapat menonaktifkan dompet.
  
  1. Tujuan tugas
  
  Gunakan class method, static method, custom decorator, chaining decorator, serta `*args` dan `**kwargs` pada wrapper.
  
  2. Spesifikasi class
  
  - `total_dompet = 0`, `total_isi_saldo = 0`, dan `total_percobaan = 0` adalah class attribute.
  - `saldo_maksimal = 2000000` adalah class attribute.
  - Constructor menerima `(nama, id_pengguna, saldo_awal)`. Simpan nama dan ID sebagai public attribute. Simpan saldo pada property `saldo` dengan private attribute `__saldo`.
  - Saldo harus berada pada rentang 0 sampai `saldo_maksimal`. Object baru menambah `total_dompet` satu kali.
  
  3. Class method dan static method
  
  - `@classmethod dari_teks(cls, teks)` menerima `nama id_pengguna saldo_awal`, mengubah underscore pada nama menjadi spasi, mengubah saldo menjadi integer, dan menggunakan `cls(...)`.
  - `@staticmethod id_valid(id_pengguna)` mengembalikan `True` jika ID terdiri dari `W` diikuti tepat lima digit.
  
  4. Decorator dan method
  
  Buat decorator `catat_percobaan` dan `hanya_aktif`. Keduanya memakai `wrapper(*args, **kwargs)` dan meneruskan argument ke function asli. Decorator pertama menaikkan `DompetDigital.total_percobaan` pada setiap pemanggilan `isi_saldo`. Decorator kedua mengembalikan `False` saat status dompet `"Nonaktif"`.
  
  Hias method `isi_saldo(jumlah)` dengan kedua decorator. Method berhasil jika jumlah lebih dari nol dan saldo baru tidak melebihi batas. Jika berhasil, ubah saldo melalui property dan tambah `total_isi_saldo` sebesar jumlah uang yang masuk. Jika gagal, saldo tetap.
  
  `nonaktifkan()` mengubah status menjadi `"Nonaktif"`; `status()` mengembalikan status tersebut atau `"Aktif"`.
  
  5. Program utama dan output
  
  Input: `nama id_pengguna saldo_awal jumlah id_uji nonaktif`. Program utama memanggil `isi_saldo` dengan keyword argument `jumlah`.
  
  Output harus tepat sembilan baris sesuai starter code.
  
  6. Aturan dan checklist
  
  - Lengkapi TODO saja dan jangan mengubah program utama.
  - Factory memakai `cls`; validator tidak memakai `self` atau `cls`.
  - Chaining decorator tidak boleh dilepas.
  - Wrapper harus meneruskan `*args`, `**kwargs`.
  - Isi saldo invalid tidak mengubah saldo dan counter uang.
  - Jangan menggunakan inheritance/library tambahan.
