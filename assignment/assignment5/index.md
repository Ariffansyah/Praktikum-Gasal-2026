# Assignment 5

**Chapter 7 - Polymorphism and Class Relationships:** [Live Practicum 5]({{ '/assignment/assignment5/studycase5/' | relative_url }}) (in-class) dan [Homework 5]({{ '/assignment/assignment5/homework/' | relative_url }}) (take-home).

Gunakan satu kontrak pemanggilan untuk beberapa jenis object, kemudian hubungkan object sesuai tanggung jawabnya. Tugas menekankan overriding, duck typing, aggregation, composition, delegation, serta konsistensi state saat operasi diulang atau ditolak.

- Live practicum menyediakan satu study case untuk setiap kelas: 2025A, 2025B, dan 2025C.
- Homework menyediakan delapan varian yang dipilih secara konsisten berdasarkan NIM.
- Setiap varian dilengkapi spesifikasi, starter code dengan TODO, dan delapan test case resmi.

Pelajari [Chapter 7]({{ '/readings-chapter7/' | relative_url }}) dan [Quick Review 7]({{ '/quickreview/quickreview7/' | relative_url }}) sebelum mengerjakan. Assignment ini menggunakan satu file Python; pemecahan proyek menjadi package bukan bagian dari penilaiannya.
