  Tugas: Penyewaan Peralatan dengan Strategi Tarif

  Penyewaan menerima object Alat yang sudah ada, memvalidasi permintaan, dan mendelegasikan biaya kepada tarif aktif. Semua tarif mempunyai hitung(jumlah, durasi) -> int rupiah tidak negatif untuk jumlah/durasi positif.

  1. Spesifikasi

  - Alat dan frozen StrukSewa sudah disediakan.
  - TarifNormal.hitung(): `jumlah * durasi * 5000`.
  - TarifAcara.hitung(): `jumlah * (10000 + 3000 * durasi)`. Biaya awal berlaku per alat pada setiap transaksi.
  - TarifGratis sudah disediakan; hasil nol tetap sah dan peminjaman tetap mengurangi stok bila permintaan valid.
  - Penyewaan(alat, tarif): salin container alat dengan elemen yang sama; simpan tarif dan buat _riwayat baru.
  - ganti_tarif(tarif): ganti kolaborator tanpa menghitung ulang struk lama.
  - pinjam(kode, jumlah, durasi): tolak jika kode tidak ada, jumlah/durasi tidak positif, atau stok tidak cukup. Jika ditolak, kembalikan False tanpa mengubah stok maupun riwayat. Jika diterima, hitung biaya melalui tarif, kurangi stok, buat StrukSewa baru, simpan, dan kembalikan True.
  - riwayat(): list baru teks kode/jumlah/durasi=biaya dalam urutan transaksi yang diterima.
  - total(): jumlah biaya seluruh struk; riwayat kosong menghasilkan 0.

  2. Input

  n (0..20); n baris kode nama stok dengan kode unik, nama tanpa spasi atau memakai underscore, stok integer >=0. Lalu m (0..20); m baris jenis kode jumlah durasi. Jenis normal/acara/gratis. Kode permintaan dapat tidak dikenal, jumlah/durasi dapat nol atau negatif untuk menguji penolakan. Tidak ada pengembalian alat pada varian ini.

  3. Output

  Ikuti tujuh label program utama. Stok menampilkan data object asal setelah transaksi. Tampilan Aman harus tetap sama setelah list riwayat yang diterima pemakai dikosongkan. Penyewaan kedua harus independen.

  Jelaskan aggregation alat, composition struk, delegation tarif, dan state yang dilindungi saat operasi ditolak.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `A Proyektor 5`
  - `B Kamera 2`
  - `3`
  - `normal A 2 3`
  - `acara B 1 2`
  - `gratis A 1 1`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Status: [True, True, True]`
  - `Stok: [('A', 2), ('B', 1)]`
  - `Riwayat: ['A/2/3=30000', 'B/1/2=16000', 'A/1/1=0']`
  - `Total: 46000`
  - `Referensi: True`
  - `Tampilan Aman: ['A/2/3=30000', 'B/1/2=16000', 'A/1/1=0']`
  - `Pusat Lain: [] 0`
