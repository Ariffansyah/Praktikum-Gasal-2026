prompt: |
  Tugas: Ekspor Laporan dengan Formatter Pengganti

  Formatter menyediakan format(peserta) -> str. Pelapor hanya memilih dan mengurutkan data, lalu mendelegasikan pembentukan teks.

  1. Spesifikasi

  - Peserta(nim, nama, nilai) dan frozen BarisEkspor(nim, isi) sudah disediakan.
  - FormatTeks.format(): <nim> <nama> <nilai> dengan satu spasi sebagai pemisah.
  - FormatCSV.format(): <nim>;<nama>;<nilai>. Pada input tidak ada karakter semicolon atau tanda petik sehingga escaping CSV tidak diperlukan dalam latihan ini.
  - FormatBertanda(formatter, tanda).format(): kembalikan [<tanda>] diikuti satu spasi dan hasil formatter.format(peserta). Jangan menyalin logika formatter ke wrapper.
  - FormatAnonim sudah disediakan dan harus diterima tanpa pengecekan jenis konkret.
  - Pelapor(peserta): salin container list dan pertahankan referensi peserta; _baris awal kosong.
  - ekspor(formatter, minimum): ambil peserta dengan nilai >= minimum, urutkan berdasarkan NIM string menaik, dan ganti _baris dengan LIST BARU BarisEkspor. Jangan mengubah urutan list peserta atau menghitung ulang baris lama.
  - baris(): list baru berisi teks ekspor aktif. len(pelapor): jumlah baris ekspor aktif.

  2. Input

  n (0..20); n baris nim nama nilai. NIM unik, nama memakai underscore untuk spasi, nilai 0..100. Baris terakhir minimum1 minimum2 tanda; batas boleh di luar 0..100 dan tanda memakai underscore untuk spasi.

  3. Output

  Ikuti sembilan label program utama. Setelah ekspor teks pertama, nama object peserta pertama diubah menjadi Revisi. Ekspor CSV berikutnya mencerminkan perubahan ini, tetapi snapshot ekspor teks tidak berubah. Format anonim diproses dua kali tanpa menumpuk baris. Urutan Asal dan Urutan Akhir tetap sama.

  Jelaskan aggregation peserta, composition baris, wrapper/delegation formatter, dan pemisahan sort/filter dari logika format. Lengkapi TODO saja.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `25051204003 Citra 75`
  - `25051204001 Andi 90`
  - `25051204002 Sari_Putri 60`
  - `70 60 FINAL`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Teks: ['25051204001 Andi 90', '25051204003 Citra 75']`
  - `Urutan Asal: ['25051204003', '25051204001', '25051204002']`
  - `Referensi: True`
  - `CSV: ['[FINAL] 25051204001;Andi;90', '[FINAL] 25051204002;Sari Putri;60', '[FINAL] 25051204003;Revisi;75']`
  - `Snapshot: ['25051204001 Andi 90', '25051204003 Citra 75']`
  - `Jumlah: 3`
  - `Tampilan Aman: ['[FINAL] 25051204001;Andi;90', '[FINAL] 25051204002;Sari Putri;60', '[FINAL] 25051204003;Revisi;75']`
  - `Anonim: ['25051204001', '25051204002', '25051204003']`
  - `Urutan Akhir: ['25051204003', '25051204001', '25051204002']`
