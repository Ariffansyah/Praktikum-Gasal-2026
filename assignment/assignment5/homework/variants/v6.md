  Tugas: Diskon Berantai dan Wrapper Bersyarat

  Semua strategi menyediakan hitung(nominal) -> int. Untuk nominal tidak negatif, hasil wajib berada antara 0 dan nominal. Kasir tidak memilih rumus berdasarkan jenis strategi.

  1. Spesifikasi

  - Persen(label, nilai).hitung(nominal): `nominal - (nominal * nilai // 100)`. Nilai persen 0..100; yang dibulatkan ke bawah adalah besar potongannya.
  - Tetap(label, nilai).hitung(nominal): max(0, nominal - nilai), dengan nilai potongan >=0.
  - MinimumBelanja(label, ambang, potongan) sudah membuat object Tetap pada self.diskon. hitung(nominal) mendelegasikan ke self.diskon.hitung() jika nominal >= ambang; selain itu kembalikan nominal yang sama. Ambang dan potongan >=0. Periksa nominal yang diterima LANGKAH INI, bukan harga awal transaksi.
  - TanpaDiskon sudah disediakan dan memenuhi kontrak tanpa inheritance bersama.
  - KasirDiskon(diskon): salin container strategi, buat _langkah kosong dan akhir=0.
  - proses(nominal): jika negatif, kembalikan False tanpa mengubah akhir maupun _langkah. Jika valid, terapkan semua strategi BERURUTAN; input strategi berikutnya adalah hasil strategi sebelumnya. Buat Langkah(label, sebelum, sesudah) baru per strategi, ganti list _langkah dan akhir, lalu kembalikan True. Rangkaian kosong menghasilkan nominal awal.
  - riwayat(): list baru teks label:sebelum->sesudah. Snapshot lama tetap utuh setelah proses berikutnya.

  2. Input

  n (0..20); n baris jenis label a b. Jenis persen memakai a sebagai persen dan b=0; tetap memakai a sebagai potongan dan b=0; minimum memakai a sebagai ambang serta b sebagai potongan; tanpa memakai a=b=0. Parameter strategi sudah valid. Baris terakhir nominal1 nominal2; nilai ini dapat negatif untuk menguji penolakan.

  3. Output

  Ikuti sembilan label program utama. Jika proses pertama ditolak, harga tetap 0 dan riwayat kosong. Jika proses kedua ditolak, hasil proses pertama tetap berlaku. Mengubah list tampilan tidak boleh memengaruhi riwayat internal.

  Jelaskan aggregation strategi, composition langkah dan diskon internal wrapper, delegation, serta kontrak harga yang dijaga setiap implementasi.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `persen P10 10 0`
  - `minimum MIN 80000 5000`
  - `tetap T 2000 0`
  - `100000 50000`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Proses 1: True`
  - `Harga 1: 83000`
  - `Langkah 1: ['P10:100000->90000', 'MIN:90000->85000', 'T:85000->83000']`
  - `Proses 2: True`
  - `Harga 2: 43000`
  - `Langkah 2: ['P10:50000->45000', 'MIN:45000->45000', 'T:45000->43000']`
  - `Snapshot: ['P10:100000->90000', 'MIN:90000->85000', 'T:85000->83000']`
  - `Tampilan Aman: ['P10:50000->45000', 'MIN:45000->45000', 'T:45000->43000']`
  - `Kasir Lain: 0 []`
