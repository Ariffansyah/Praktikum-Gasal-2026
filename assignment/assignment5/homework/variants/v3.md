prompt: |
  Tugas: Rekap Nilai dengan Pembaruan Atomik

  Kelas menyimpan referensi mahasiswa dan membuat snapshot nilai melalui object penilai. Semua penilai menyediakan hitung(tugas, ujian) -> int. Tidak boleh ada percabangan jenis penilai di proses().

  1. Spesifikasi

  - Mahasiswa dan frozen HasilNilai sudah disediakan. Constructor KelasNilai sudah membuat peserta serta _hasil terpisah untuk setiap instance.
  - PenilaiReguler.hitung(): `(40*tugas + 60*ujian) // 100`. PenilaiProyek.hitung(): `(70*tugas + 30*ujian) // 100`.
  - PenilaiMaksimum sudah disediakan. Terima object ini melalui kontrak yang sama.
  - daftar(mahasiswa): tolak NIM yang sudah terdaftar dan kembalikan False tanpa mengganti object lama; jika baru, simpan referensinya dan kembalikan True.
  - ubah_nilai(nim, tugas, ujian): hanya berhasil jika NIM ada dan kedua skor integer dalam 0..100. Jika salah satu tidak valid, kembalikan False tanpa mengubah kedua skor. Jika valid, ubah kedua field pada object mahasiswa lalu kembalikan True. Catatan _hasil belum berubah sebelum proses() berikutnya.
  - proses(penilai): ganti _hasil dengan list HasilNilai baru dalam urutan peserta; perhitungan didelegasikan ke penilai.
  - laporan(): list baru teks nim=nilai dari _hasil. len(kelas): jumlah peserta unik, bukan jumlah hasil lama.

  2. Input

  n (0..20); n baris nim nama tugas ujian. Nama memakai underscore untuk spasi. Skor awal 0..100; NIM dapat berulang dan pendaftaran pertama dipertahankan. Baris terakhir target_nim tugas_baru ujian_baru; skor pembaruan dapat di luar rentang agar operasi ditolak. Tidak perlu memvalidasi format NIM di dalam soal ini.

  3. Output

  Ikuti 11 label program utama. Data adalah list tuple (nim, tugas, ujian) peserta yang diterima, sesuai urutan pendaftaran. Referensi untuk daftar kosong bernilai True. Snapshot lama tetap mencerminkan nilai reguler pertama. Pemrosesan berulang tidak boleh menumpuk hasil.

  Jelaskan aggregation mahasiswa, composition catatan, delegation kebijakan, dan alasan pembaruan gagal tidak mengubah sebagian data.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `25051204001 Andi 80 90`
  - `25051204002 Sari 100 80`
  - `25051204001 0 90`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Daftar: [True, True]`
  - `Jumlah: 2`
  - `Referensi: True`
  - `Reguler: ['25051204001=86', '25051204002=88']`
  - `Ubah: True`
  - `Sebelum Rekap: ['25051204001=86', '25051204002=88']`
  - `Data: [('25051204001', 0, 90), ('25051204002', 100, 80)]`
  - `Proyek: ['25051204001=27', '25051204002=94']`
  - `Snapshot: ['25051204001=86', '25051204002=88']`
  - `Maksimum: ['25051204001=90', '25051204002=100']`
  - `Kelas Lain: []`
