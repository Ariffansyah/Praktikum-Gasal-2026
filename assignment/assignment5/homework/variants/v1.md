prompt: |
  Tugas: Paket Layanan dan Wrapper Diskon

  Fotokopi, poster, layanan mitra, serta paket memiliki kontrak total() -> int. Pemroses tidak boleh membedakan jenis konkret komponen untuk menghitung biaya. Paket bertingkat dibentuk oleh program utama; graph input tidak bersiklus.

  1. Spesifikasi

  - Fotokopi.total(): `unit * 300`. Poster.total(): `unit * 2500`. LayananMitra.total() sudah tersedia: `unit * 500`.
  - PaketLayanan(kode, komponen): simpan kode dan container list baru; elemen tetap object yang diberikan.
  - PaketLayanan.total(): jumlah total() setiap komponen. Komponen dapat berupa layanan atau paket lain.
  - tambah(komponen): tolak object paket itu sendiri dan kode yang sudah ada pada komponen langsung. Kembalikan False tanpa perubahan jika ditolak; selain itu simpan referensinya dan kembalikan True. Tidak perlu mendeteksi siklus tak langsung yang tidak diberikan oleh program utama.
  - len(paket): jumlah komponen langsung, bukan jumlah seluruh leaf bertingkat.
  - DiskonPaket(paket, persen) menyimpan kolaborator; total() mengembalikan `awal - (awal * persen // 100)`. Wrapper tidak mengubah paket atau biaya komponennya. Persen 0..100.

  2. Input

  n (0..20); n baris jenis kode unit dengan jenis foto/poster/mitra, kode unik dan bukan TAMBAHAN, unit 0..1000; lalu persen tambahan (tambahan 0..1000). Semua angka integer valid. Program utama menambah unit komponen pertama melalui referensi asal, mencoba duplikat, dan menambah poster TAMBAHAN.

  3. Output

  Ikuti 12 label pada program utama. Bertingkat adalah total paket LUAR yang berisi paket UTAMA dan fotokopi BONUS dua lembar. Duplikat dicetak False untuk daftar awal kosong tanpa memanggil tambah(). Referensi kosong juga didefinisikan True oleh program utama. Tambah pada akhir harus True.

  Hubungan yang harus dijelaskan: aggregation komponen, composite yang dapat diproses melalui total(), dan delegation pada wrapper diskon. Lengkapi TODO saja.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `foto A 10`
  - `poster B 2`
  - `mitra C 1`
  - `10 3`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Dasar: 8500`
  - `Diskon: 7650`
  - `Bertingkat: 9100`
  - `Duplikat: False`
  - `Diri Sendiri: False`
  - `Jumlah: 3`
  - `Referensi: True`
  - `Dasar Baru: 9400`
  - `Diskon Baru: 8460`
  - `Tambah: True`
  - `Akhir: 11900 4`
  - `Kosong: 0`
