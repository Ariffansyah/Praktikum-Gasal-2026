  Tugas: Arsip Dokumen dan Operator Penggabungan

  Seluruh berkas menyediakan halaman() -> int tidak negatif. Arsip mengagregasi berkas dan membuat manifest snapshot. Penggabungan arsip menghasilkan object baru.

  1. Spesifikasi

  - Berkas, constructor entity, RingkasanEksternal, dan frozen EntriManifest(kode, halaman) sudah disediakan.
  - PDF.halaman(): unit. Slide.halaman(): (unit + 3) // 4, yaitu empat slide per halaman dan sisa dibulatkan ke atas. Unit nol menghasilkan nol halaman.
  - Arsip(nama, berkas): simpan nama, salin container berkas dengan elemen yang sama, dan buat catatan kosong milik instance.
  - len(arsip): jumlah berkas, bukan jumlah halaman.
  - kiri + kanan: jika operand kanan bukan instance Arsip, kembalikan NotImplemented. Jika sesuai, buat Arsip baru bernama kiri.nama + '+' + kanan.nama. Gabungkan dalam urutan kiri lalu kanan; jika kode duplikat, pertahankan object yang muncul pertama. Jangan mengubah container kedua operand dan jangan menyalin object berkasnya.
  - total_halaman(): jumlah hasil halaman() setiap berkas melalui pemanggilan polymorphic.
  - buat_manifest(): ganti catatan dengan LIST BARU EntriManifest dari kode dan hasil halaman() saat itu. Jangan mengubah catatan snapshot lama.
  - manifest(): list baru teks kode=halaman dari catatan aktif, bukan menghitung ulang berkas.

  2. Input

  n_kiri (0..20), lalu n_kiri baris jenis kode unit. Berikutnya n_kanan dan baris-barisnya. Baris terakhir tambahan integer 0..1000. Jenis pdf/slide/mitra, unit integer 0..1000. Kode unik di dalam setiap arsip tetapi boleh sama antararsip. Program utama menambah unit berkas kiri pertama jika ada.

  3. Output

  Ikuti 14 label program utama. Manifest lama tidak berubah sampai dibuat ulang. Total halaman baru mencerminkan perubahan object asal yang masih dirujuk arsip gabungan. Asal Tetap memeriksa jumlah berkas pada container operand. Tipe Salah bernilai True karena operator tidak mendukung penjumlahan dengan integer.

  Pemeriksaan isinstance(other, Arsip) pada __add__ diperbolehkan untuk kompatibilitas operand. Jangan memakai pemeriksaan jenis berkas untuk menggantikan halaman(). Jelaskan aggregation, operator overloading, delegation, dan composition manifest. Lengkapi TODO saja.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `pdf A 10`
  - `slide B 5`
  - `2`
  - `slide A 100`
  - `mitra C 3`
  - `2`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.

  - `Kanan: ['A', 'C']`

  - `Tampilan Aman: ['A=12', 'B=2', 'C=3']`
  - `Tipe Salah: True`
  - `Kosong: 0 0 []`
