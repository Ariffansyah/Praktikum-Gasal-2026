  Tugas: Kelas Berkapasitas dan Pergantian Mode

  Semua mode memiliki kapasitas() -> int tidak negatif. Kelas memakai kontrak ini, bukan nama class konkret.

  1. Spesifikasi

  - Peserta(nim, nama) sudah tersedia. TatapMuka.kapasitas() mengembalikan kursi; Daring mengembalikan lisensi; Hibrida mengembalikan min(kursi, lisensi). Constructor sudah disediakan.
  - ModeCadangan sudah disediakan; class ini juga harus dapat digunakan melalui kontrak kapasitas().
  - Kelas(mode) sudah menyimpan mode dan membuat list peserta milik instance.
  - daftar(peserta): tolak jika NIM sudah ada ATAU jumlah peserta sudah mencapai kapasitas. Jika ditolak, False tanpa perubahan. Jika diterima, simpan referensi yang diberikan dan kembalikan True.
  - keluar(nim): hapus keanggotaan dengan NIM itu dan kembalikan True; jika tidak ada, False. Object asal tidak diubah.
  - ganti_mode(mode): hanya diterima jika kapasitas mode baru >= jumlah peserta saat ini. Jika ditolak, mode lama dan peserta tetap utuh. Jika diterima, simpan kolaborator baru. Kembalikan status boolean.
  - anggota(): list baru teks nim:nama sesuai urutan pendaftaran yang masih aktif.
  - nim in kelas menggunakan __contains__() untuk mencari NIM. len(kelas) adalah jumlah peserta aktif.

  2. Input

  Baris pertama jenis kursi lisensi (jenis tatap/daring/hibrida, angka 0..50). Baris kedua n (0..20), lalu n baris nim nama. Nama memakai underscore untuk spasi; NIM boleh berulang. Berikutnya jenis_baru kursi_baru lisensi_baru; target_nim yang dikeluarkan; nim_baru nama_baru yang dicoba masuk; dan kapasitas_cadangan 0..50. Semua berada pada baris terpisah seperti test.

  3. Output

  Ikuti 14 label program utama. Kapasitas dicetak setelah upaya pergantian pertama; Kapasitas Akhir setelah upaya mode cadangan. Object Mandiri menampilkan nama seluruh object pendaftaran awal, termasuk yang pernah ditolak atau dikeluarkan. Referensi memeriksa bahwa peserta aktif adalah object yang diterima, bukan salinan. List dari anggota() boleh diubah pemakai tanpa merusak keanggotaan.

  Jelaskan aggregation peserta, association dengan mode, delegation kapasitas, dan alasan mode pengganti tidak boleh melanggar kapasitas peserta yang sudah diterima.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `tatap 2 9`
  - `3`
  - `25051204001 Andi`
  - `25051204002 Sari`
  - `25051204003 Budi`
  - `hibrida 1 3`
  - `25051204001`
  - `25051204003 Budi`
  - `3`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Daftar: [True, True, False]`
  - `Awal: ['25051204001:Andi', '25051204002:Sari']`
  - `Mode Baru: False`
  - `Kapasitas: 2`
  - `Keluar: True`
  - `Tambah: True`
  - `Cadangan: True`
  - `Akhir: ['25051204002:Sari', '25051204003:Budi']`

  - `Target Ada: False`
  - `Kapasitas Akhir: 3`
  - `Tampilan Aman: ['25051204002:Sari', '25051204003:Budi']`
  - `Referensi: True`
  - `Object Mandiri: ['Andi', 'Sari', 'Budi']`
