prompt: |
  Tugas: Pengumuman Multikanal dengan Riwayat

  Kontrak kanal adalah kirim(penerima, pesan) -> str. Seluruh kanal hanya memformat teks; tidak ada pengiriman email atau jaringan.

  1. Spesifikasi

  - Penerima(nim, nama) dan frozen CatatanPesan(nim, isi) sudah disediakan.
  - KanalEmail.kirim(): E[<nim>]:<pesan>. KanalLayar.kirim(): L[<nama>]:<pesan>.
  - KanalAwalan(kanal, awalan).kirim(): delegasikan ke kanal.kirim() dengan pesan baru <awalan>|<pesan>. Jangan mencetak atau menulis ulang format kanal.
  - KanalArsip sudah disediakan dan harus diterima tanpa pengecekan class konkret.
  - PusatPesan(penerima, kanal): salin list penerima dengan identitas elemen tetap sama, simpan kanal, dan buat _riwayat kosong milik instance.
  - kirim(pesan): jika pesan kosong, kembalikan False tanpa perubahan. Jika valid, buat CatatanPesan baru untuk setiap penerima sesuai urutan, simpan hasil kanal, lalu kembalikan True. Daftar penerima kosong dengan pesan valid tetap menghasilkan True tetapi tidak menambah catatan.
  - ganti(kanal): ganti kolaborator. riwayat(): kembalikan LIST BARU berisi isi seluruh catatan. len(pusat): jumlah catatan, bukan jumlah pengiriman pesan.

  2. Input

  n (0..20); n baris nim nama (NIM unik). Berikutnya tiga baris: awalan, pesan1, pesan2. Underscore mewakili spasi. Pesan '-' berarti kosong; awalan selalu satu token tidak kosong. Tidak ada karakter tanda petik pada data.

  3. Output

  Ikuti sembilan baris pada program utama. Setelah pengiriman pertama, nama penerima pertama diubah menjadi Revisi. Pengiriman kedua memakai kanal layar, lalu Audit memakai kanal arsip. Snapshot lama tidak berubah. Mengosongkan list hasil riwayat() tidak boleh mengosongkan data internal.

  Jelaskan aggregation penerima, composition catatan, dan delegation pada pusat/wrapper. Lengkapi TODO saja.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `25051204001 Andi`
  - `25051204002 Sari_Putri`
  - `INFO`
  - `Mulai`
  - `Selesai`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Kirim 1: True`
  - `Awal: ['E[25051204001]:INFO|Mulai', 'E[25051204002]:INFO|Mulai']`
  - `Setelah Tampilan Diubah: ['E[25051204001]:INFO|Mulai', 'E[25051204002]:INFO|Mulai']`
  - `Kirim 2: True`
  - `Arsip: True`
  - `Riwayat: ['E[25051204001]:INFO|Mulai', 'E[25051204002]:INFO|Mulai', 'L[Revisi]:Selesai', 'L[Sari Putri]:Selesai', 'A[25051204001]:Audit', 'A[25051204002]:Audit']`
  - `Snapshot: ['E[25051204001]:INFO|Mulai', 'E[25051204002]:INFO|Mulai']`
  - `Jumlah: 6`
  - `Pusat Lain: [] 0`
