prompt: |
  Tugas: Layanan Cetak Kampus

  Proses beberapa object dengan satu kontrak hitung() -> int. Setiap object memiliki kode dan unit, dengan unit berarti lembar. Object mitra menyediakan kontrak yang sama tanpa mewarisi PekerjaanCetak.

  1. Spesifikasi

  - PekerjaanCetak, constructor entity, CetakMitra, serta frozen data class CatatanBiaya(kode, biaya) sudah disediakan.
  - CetakMono.hitung(): `unit * 300`. Jenis input: mono.
  - CetakWarna.hitung(): `unit * 1000`. Jenis input: warna.
  - CetakMitra.hitung(): `unit * 450`. Jenis input: mitra. Jangan mengubah class ini.
  - AntreanCetak(daftar): simpan list baru pada item dengan elemen object yang sama. Buat catatan sebagai list kosong milik instance.
  - proses(): buat dan simpan LIST BARU berisi CatatanBiaya(x.kode, x.hitung()) sesuai urutan item. Hasil lama tidak boleh diubah atau dipakai ulang sebagai list aktif. Method tidak perlu mengembalikan nilai.
  - ringkasan(): kembalikan list teks kode=biaya dari catatan yang sudah dibuat, bukan menghitung ulang data sumber.
  - total(): jumlah biaya dalam catatan aktif; daftar kosong menghasilkan 0.
  - len(pusat): jumlah catatan aktif, bukan total unit.

  2. Hubungan object

  item mengagregasi object dari luar. Perubahan unit pada object asal terlihat saat proses berikutnya. Catatan dibuat oleh pengelola sebagai snapshot hasil. Pengelola mendelegasikan rumus kepada hitung(), bukan memeriksa jenis class.

  3. Format input

  Baris pertama n (0..20). Berikutnya n baris: jenis kode unit. Jenis adalah mono, warna, atau mitra; kode unik tanpa spasi; unit integer 0..1000. Baris terakhir tambahan integer 0..1000, yang ditambahkan program utama pada unit object pertama jika ada. Semua input memenuhi format ini.

  4. Format output

  Program utama mencetak 11 baris berlabel Awal, Total Awal, Jumlah, Referensi, Sebelum Proses, Baru, Total Baru, Snapshot, Ulang, Kosong, dan Mitra Subclass. Python list memakai format standar seperti pada test. Referensi bernilai True bila daftar kosong atau identitas elemen pertama terjaga. Mitra Subclass harus False, tetapi object mitra tetap diproses.

  Lengkapi tujuh TODO method. Jangan mengubah factory dan program utama. Proses ulang menggantikan catatan; snapshot lama serta pengelola kosong tetap independen.

  5. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `mono A01 2`
  - `warna B02 3`
  - `mitra M03 1`
  - `2`

  6. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Awal: ['A01=600', 'B02=3000', 'M03=450']`
  - `Total Awal: 4050`
  - `Jumlah: 3`
  - `Referensi: True`
  - `Sebelum Proses: ['A01=600', 'B02=3000', 'M03=450']`
  - `Baru: ['A01=1200', 'B02=3000', 'M03=450']`
  - `Total Baru: 4650`
  - `Snapshot: ['A01=600', 'B02=3000', 'M03=450']`
  - `Ulang: ['A01=1200', 'B02=3000', 'M03=450']`
  - `Kosong: [] 0 0`
  - `Mitra Subclass: False`
