prompt: |
  Tugas: Pengiriman Paket Kampus

  Proses beberapa object dengan satu kontrak hitung() -> int. Setiap object memiliki kode dan unit, dengan unit berarti kilogram. Object mitra menyediakan kontrak yang sama tanpa mewarisi Paket.

  1. Spesifikasi

  - Paket, constructor entity, PaketMitra, serta frozen data class CatatanBiaya(kode, biaya) sudah disediakan.
  - PaketReguler.hitung(): `unit * 2000`. Jenis input: reguler.
  - PaketEkspres.hitung(): `unit * 4000`. Jenis input: ekspres.
  - PaketMitra.hitung(): `unit * 3000`. Jenis input: mitra. Jangan mengubah class ini.
  - PusatPengiriman(daftar): simpan list baru pada item dengan elemen object yang sama. Buat catatan sebagai list kosong milik instance.
  - proses(): buat dan simpan LIST BARU berisi CatatanBiaya(x.kode, x.hitung()) sesuai urutan item. Hasil lama tidak boleh diubah atau dipakai ulang sebagai list aktif. Method tidak perlu mengembalikan nilai.
  - ringkasan(): kembalikan list teks kode=biaya dari catatan yang sudah dibuat, bukan menghitung ulang data sumber.
  - total(): jumlah biaya dalam catatan aktif; daftar kosong menghasilkan 0.
  - len(pusat): jumlah catatan aktif, bukan total unit.

  2. Hubungan object

  item mengagregasi object dari luar. Perubahan unit pada object asal terlihat saat proses berikutnya. Catatan dibuat oleh pengelola sebagai snapshot hasil. Pengelola mendelegasikan rumus kepada hitung(), bukan memeriksa jenis class.

  3. Format input

  Baris pertama n (0..20). Berikutnya n baris: jenis kode unit. Jenis adalah reguler, ekspres, atau mitra; kode unik tanpa spasi; unit integer 0..1000. Baris terakhir tambahan integer 0..1000, yang ditambahkan program utama pada unit object pertama jika ada. Semua input memenuhi format ini.

  4. Format output

  Program utama mencetak 11 baris berlabel Awal, Total Awal, Jumlah, Referensi, Sebelum Proses, Baru, Total Baru, Snapshot, Ulang, Kosong, dan Mitra Subclass. Python list memakai format standar seperti pada test. Referensi bernilai True bila daftar kosong atau identitas elemen pertama terjaga. Mitra Subclass harus False, tetapi object mitra tetap diproses.

  Lengkapi tujuh TODO method. Jangan mengubah factory dan program utama. Proses ulang menggantikan catatan; snapshot lama serta pengelola kosong tetap independen.

  5. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `reguler A01 2`
  - `ekspres B02 3`
  - `mitra M03 1`
  - `2`

  6. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Awal: ['A01=4000', 'B02=12000', 'M03=3000']`
  - `Total Awal: 19000`
  - `Jumlah: 3`
  - `Referensi: True`
  - `Sebelum Proses: ['A01=4000', 'B02=12000', 'M03=3000']`
  - `Baru: ['A01=8000', 'B02=12000', 'M03=3000']`
  - `Total Baru: 23000`
  - `Snapshot: ['A01=4000', 'B02=12000', 'M03=3000']`
  - `Ulang: ['A01=8000', 'B02=12000', 'M03=3000']`
  - `Kosong: [] 0 0`
  - `Mitra Subclass: False`
