prompt: |
  Tugas
  
  Implementasikan tiga class terpisah, `Buku`, `Anggota`, dan `Perpustakaan`, yang bekerja sama tanpa inheritance. Satu input membuat satu object dari masing-masing class, lalu `Perpustakaan` memproses satu percobaan peminjaman dan satu percobaan pengembalian antara object `Buku` dan object `Anggota` tersebut.
  
  1. Tujuan Pembelajaran
  
  Terapkan class attribute, instance attribute, public attribute, protected attribute, private attribute dengan name mangling, property getter/setter, dan instance method pada beberapa class yang berkolaborasi lewat composition (bukan inheritance).
  
  2. Spesifikasi Class `Buku`
  
  Gunakan class bernama `Buku` dengan constructor `__init__(self, judul, penulis, stok=1)`.
  
  - `total_buku = 0` adalah class attribute. Tambahkan tepat satu setiap object `Buku` dibuat.
  - `judul` dan `penulis` adalah public instance attribute.
  - `__stok` adalah private instance attribute, diakses lewat property `stok`.
  - Setter `stok` harus menghasilkan `ValueError("Stok tidak boleh negatif.")` jika nilai kurang dari nol.
  
  3. Spesifikasi Class `Anggota`
  
  Gunakan class bernama `Anggota` dengan constructor `__init__(self, nama, kode_anggota)`.
  
  - `total_anggota = 0` adalah class attribute. Tambahkan tepat satu setiap object `Anggota` dibuat.
  - `batas_pinjam = 3` adalah class attribute, jumlah maksimum buku yang boleh dipinjam Anggota pada saat bersamaan.
  - `nama` dan `kode_anggota` adalah public instance attribute.
  - `_status` adalah protected instance attribute, diisi `"Aktif"` di constructor.
  - `__jumlah_pinjam` adalah private instance attribute, diakses lewat property `jumlah_pinjam`.
  - Setter `jumlah_pinjam` harus menghasilkan `ValueError("Jumlah pinjam harus berada pada rentang 0 sampai batas_pinjam.")` jika nilai di luar rentang 0 sampai `batas_pinjam`.
  
  4. Spesifikasi Class `Perpustakaan`
  
  Gunakan class bernama `Perpustakaan` dengan constructor `__init__(self, nama)`.
  
  - `total_transaksi = 0` adalah class attribute. Tambahkan tepat satu setiap `pinjamkan` atau `kembalikan` yang berhasil.
  - `nama` adalah public instance attribute.
  - `Perpustakaan` tidak boleh menyimpan salinan data `Buku` atau `Anggota`. Object tersebut diterima sebagai parameter method, bukan disimpan sebagai atribut. Ini murni composition antar object, bukan inheritance.
  
  Method `Perpustakaan`:
  
  - `pinjamkan(self, buku, anggota, jumlah)` mengembalikan `True` jika `jumlah` lebih dari nol, tidak lebih besar dari `buku.stok`, dan `anggota.jumlah_pinjam + jumlah` tidak melebihi `Anggota.batas_pinjam`. Jika berhasil, kurangi `buku.stok` dan tambah `anggota.jumlah_pinjam` lewat property masing-masing, lalu tambah `total_transaksi`. Jika gagal, kembalikan `False` tanpa mengubah state apa pun.
  - `kembalikan(self, buku, anggota, jumlah)` mengembalikan `True` jika `jumlah` lebih dari nol dan tidak lebih besar dari `anggota.jumlah_pinjam`. Jika berhasil, tambah `buku.stok` dan kurangi `anggota.jumlah_pinjam` lewat property masing-masing, lalu tambah `total_transaksi`. Jika gagal, kembalikan `False` tanpa mengubah state apa pun.
  
  Semua perubahan `stok` dan `jumlah_pinjam` di dalam kedua method ini harus melalui property, bukan lewat name-mangled attribute secara langsung.
  
  5. Program Utama
  
  Jangan mengubah bagian program utama pada starter code.
  
  Format Input:
  `judul penulis stok nama kode_anggota jumlah_pinjam jumlah_kembali`
  
  `judul`, `penulis`, dan `nama` menggunakan underscore sebagai pengganti spasi. Program utama sudah mengubah underscore menjadi spasi.
  
  Format Output harus tepat sebelas baris sesuai starter code:
  `Judul Buku`, `Penulis`, `Nama Anggota`, `Kode Anggota`, `Stok Tersisa`, `Jumlah Dipinjam Anggota`, `Pinjam Berhasil`, `Kembali Berhasil`, `Total Buku`, `Total Anggota`, dan `Total Transaksi`.
  
  6. Constraints
  
  - `stok`, `jumlah_pinjam`, dan `jumlah_kembali` dibaca sebagai integer.
  - Nilai jumlah operasi dapat nol atau negatif. Tangani nilai tersebut dengan mengembalikan `False`, bukan dengan mengubah state.
  - Jangan menggunakan inheritance dalam bentuk apa pun; ketiga class berdiri sendiri dan berkolaborasi lewat parameter method.
  - Jangan menambahkan print lain karena output dibandingkan secara tepat.
  - Jangan mengganti nama class, attribute, property, method, signature, atau format output.
  
  7. Checklist sebelum Run Tests
  
  - `Perpustakaan` tidak menyimpan object `Buku`/`Anggota` sebagai atribut, hanya menerimanya sebagai parameter.
  - `pinjamkan` memeriksa stok DAN batas pinjam anggota sebelum mengubah apa pun.
  - Kegagalan peminjaman dan pengembalian tidak mengubah state `Buku` maupun `Anggota`.
  - `total_transaksi` hanya bertambah saat `pinjamkan`/`kembalikan` benar-benar berhasil.
  - Semua output memiliki label dan kapitalisasi yang sama dengan starter code.
